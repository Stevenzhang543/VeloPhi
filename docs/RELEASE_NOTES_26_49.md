# Verity 26.49 发布说明

文档日期：2026-10-24 · 版本 26.49.0

Verity（暂名）是面向物理专业学生、物理老师和爱好者的二维力学仿真与教学引擎。26.49 根据 26.48 的使用反馈做了六件事：找回前作 Nova_A 中好用的编辑方式（拖拽创建、在网格上拉伸顶点）；新增完整的设置页和“渲染与监视”页；加强画面（动态玻璃、运动模糊、粒子）；修复页面切换卡顿、按播放后画面不动；升级求解器（碰撞摩擦、时间步进后备、后台线程计算）并统一全局单位；按 `DEV_MANUAL_26_49.md` 完成新模型、课件导出和教学工具。师生试用（手册 P0）尚未进行，见“已知限制”。

## 本版内容

### 物理与求解器

**变力 F(t, 状态)（D14）** 外力的 x、y 分量可以写成表达式，例如 `10*sin(2*pi*t)`、`5*step(t - 1)`、`-0.5*vx`。变量：t、x、y、vx、vy、v、theta、omega、m、g（受力物体的状态与质量，场景的 |g|）；常数 pi、e；函数 sin、cos、tan、asin、acos、atan、atan2、exp、ln、log、lg、sqrt、abs、min、max、sign、step、clamp、if。输入时检查语法和量纲：结果必须是力（N），数字视为带合适单位的系数。step、sign、if 的跳变和 abs、min、max、clamp 的折点作为事件精确定位，事件表记为“变力切换”或“变力折点”；在零附近反复切换的写法（如 `sign(vx)` 在 vx = 0 处）会停止计算并说明原因。含变力的场景把时间放进状态向量；变力做的功计入能量账本。

**动滑轮与多体绳** 滑轮可以装在物体上（动滑轮，坐标相对该物体质心，轮本身无质量）；一根绳可以经过若干定滑轮和动滑轮，同时作用在两个以上的物体上。

**新模板与公式** 新增 7 个模板（共 21 个）：竖直面圆周（绳）、竖直面圆周（杆）、动滑轮、可动斜面、弹簧连接体、滚动带滑动、变力 F = F₀ sin ωt。识别器新增 7 类情形、公式库新增 41 条（共 23 类、109 条）：竖直面圆周（最高点临界速度、绳松弛的位置、速率和时刻——时刻用第一类不完全椭圆积分）、杆力方向与零点、动滑轮的加速度与张力关系、可动斜面的加速度与支持力和水平动量、弹簧连接体的共速、最大弹性势能与最大形变、滚动带滑动、变力的冲量与功。二维中的圆形物体是匀质圆柱（I = ½mr²），ω₀ = 0 时打滑时间 t = v₀/(3μg)、之后以 2v₀/3 纯滚动；实心球的 2v₀/(7μg) 是三维结果，公式卡上注明不适用。

**碰撞中的摩擦** 26.48 的碰撞冲量是光滑的。26.49 对单点碰撞计入库仑摩擦：Stronge 能量恢复系数，沿冲量路径精确处理滑动、黏着和反向滑动（闭式解，铰链和杆的冲量先消去）。多个接触点同时发生的摩擦碰撞仍按光滑冲量计算，并在警告中注明。μ = 0 时结果与 26.48 逐位相同。假设光滑接触的碰撞公式（动能损失、切向速度不变、等质量弹性斜碰垂直、小球撞铰接物体）只在碰撞冲量无摩擦时给出。

**Moreau–Jean 时间步进（大场景后备）** 可以在“场景”页选择，或在事件堆积时自动切换（0.05 s 仿真时间内超过 400 个事件，或同一时刻超过 200 次状态切换）。切换后明确标为精度降级：事件表记“改用时间步进（精度降级）”，公式对照、“场景”页、监视页和导出的报告都注明，切换之后不再给出公式对照。默认的事件驱动求解不受影响。

**后台线程计算（D13）** 求解在 Web Worker 中进行，约每 100 ms 把新算出的部分发回界面，计算未完成时即可播放已算出的部分（设置“边算边播”），公式对照在计算完成后出现。无法创建 Worker 时自动改为在界面线程中分片计算（每片约 12 ms）。两种方式的记录逐位相同。

**性能** 26.48 的 14 个模板计算总耗时从 611 ms 降到 298 ms，没有模板变慢，结果指纹不变（见“性能”）。

### 编辑

- 所有添加工具都可以拖拽创建：物块、墙按对角拉出，小球、圆柱、滑轮先定圆心再拉半径，地面、传送带拉出水平范围，斜面、楔块拉出直角三角形；拖动时实时显示尺寸和坡角。单击仍按默认尺寸放置。
- 多边形工具：逐点单击，Enter 或双击闭合，Backspace 撤回上一点；结果取凸包，并以质心为原点保存。
- 选中后的手柄：矩形 8 个缩放手柄和旋转手柄；圆的半径手柄；多边形（含斜面）逐个拖动顶点、双击边插入顶点、Alt + 单击删除顶点；滑轮半径手柄。不合法的形状以红色预览且不会生效。旋转默认按 15° 吸附（Shift 自由旋转）。挂在物体上的连接点和动滑轮随形状变化保持在同一物质点上。
- 网格吸附：步长取当前可见的细网格或固定值，按住 Alt 临时关闭，吸附点有标记；测量工具还会吸附到物体中心、顶点和滑轮轴。
- 右键菜单（层次、静态 ⇄ 动态、锁定转动、矩形转多边形、清零初速度等）；Ctrl+C / Ctrl+V / Ctrl+D 复制、粘贴（到指针处）、原地复制；方向键按一个网格微移（Shift ×10）。
- 测量与标注：尺子、量角器、文字、箭头，随场景保存，出现在视频、截图和报告中；修改标注不会让已算好的结果失效。
- 工具快捷键：V 选择、H 平移、B 物块、O 小球、C 圆柱、P 多边形、G 地面、I 斜面、W 墙、M 尺子、A 量角器、T 文字、L 箭头。
- 属性面板：变力表达式编辑器（逐个分量实时检查，附变量、函数和示例说明）；滑轮可选择所在物体（动滑轮）；质量旁显示重力 G = mg；所有数值按当前单位输入和显示。

### 渲染与视觉

- 播放按连续时间进行：两帧之间没有事件时，位置用三次 Hermite 插值（由记录的位置和速度）；区间内有事件时，从上一帧按正确的接触模式精确积分。插值只用于绘制，所有读数仍来自记录帧或精确状态。
- 运动模糊：每帧在快门时间内取 6–12 个子帧状态叠加，快门可调（默认 180°）。
- 粒子：碰撞火花与扬尘、滑动处的尘土、绳突然绷紧时的一团烟。粒子没有内部状态，位置由“发射时刻 + 哈希”闭式算出，所以倒退拖动、慢放和导出视频中看到的完全相同。另有可选的渐隐拖尾。
- 投影仪模式：字号 ×1.4、线宽 ×1.75，对比度更高、不用半透明。
- 动态玻璃：半透明面板、跟随指针的高光、缓慢变化的背景。背景在窗口隐藏、系统要求减少动态效果时暂停，“标准”质量下播放时也暂停；真正的背景模糊只在“高”质量下启用。效果质量可选关闭、标准、高。

### 页面与设置

- 三个页面：工作台、渲染与监视、设置（Alt+1 / Alt+2 / Alt+3，设置也可用 Ctrl+,）。工作台右侧标签为 公式对照、属性、监视、预测、场景（“场景”即 26.48 的场景设置页）。
- 渲染与监视：大画面与播放控制；监视量以数值卡片显示（带到当前时刻的迷你曲线）；能量账本条形图；最多 4 张曲线；当前时刻的公式判定统计；事件列表（点击跳转）；计算进度。
- 设置：通用、单位与数值、显示、视觉效果、编辑、仿真、导出、快捷键、隐私与试用、关于，共 10 个分区，每个分区可单独恢复默认。设置保存在本机，不随场景文件保存。
- 页面切换不再重建：已打开的页面保持挂载，隐藏的面板停止跟随播放；公式渲染有缓存；曲线按记录缓存，播放时只移动时间光标。

### 单位

- 单一的单位表（`src/units/units.ts`）：内部一律国际单位，只在输入和显示时换算。每类量可选显示单位，例如长度 m / cm / mm / km、质量 kg / g、速度 m/s、cm/s、km/h、力 N / mN / kN、能量 J / mJ / kJ、角度 ° / rad。预设：国际单位制（角度用 °）、国际单位制（角度用 rad）、实验室尺度（cm、g、cm/s）。面板、曲线、公式代入式、画布标注、视频叠加、CSV（显示单位模式）和报告同时生效。
- 测试检查每个观测量、每条公式、每个识别变量和变力变量的单位都在单位表中。
- 重力加速度只有一个默认值：“设置 › 通用 › 新场景的重力加速度 g”（默认 9.8 m/s²），用于新建场景和所有模板；已有场景保留各自的 g，公式一律用场景的 g。

### 教学工具

- **课件包（D15）**：一次导出视频（有 H.264 编码器时为 MP4，否则 WebM）、关键时刻截图（PNG，主题背景 / 白底 / 透明）、公式卡片（PNG，可另存内嵌 KaTeX 字体的 SVG）、CSV（国际单位逐位一致，或显示单位；分隔符与小数点可选），可选 PPTX（PptxGenJS 4.0.1，MIT；每个关键时刻一页：截图 + 读数 + 公式，另有视频页）。输出为一个 ZIP 或逐个文件。
- **预测与对比**（“预测”标签）：运行前填写预测（某类事件的时刻、某时刻的物理量或公式结果），运行后与仿真值和公式值对比；预测随场景文件保存。
- **参数扫描**：选一个参数、范围和最多 50 个取值，逐个运行，画出“结果–参数”曲线（uPlot），可导出 CSV 和图片。
- **实验报告**：单个自包含 HTML（场景与参数、截图、曲线、公式对照与误差、事件、预测、结果指纹），离线可打开；通过系统打印对话框另存为 PDF。
- **试用日志（D16）**：默认关闭；开启后只在本机记录操作类型和标识符（最多 5000 条，不含姓名、文件名、路径和输入的文字），从不上传；在“设置 › 隐私与试用”中导出或清除。试用任务单见 `docs/reports/trial-26.49.md`。

### 修复

- 按播放后画面不动、直到停止才刷新：绘制请求每帧合并一次且不再被取消。
- 页面和标签切换卡顿：见“页面与设置”；无头 Chromium 中实测切换一次（点击到第二帧）为 20–47 ms。
- 监视列表中按另一种顺序加入的接触对物理量显示为原始 id（如 `pair.block|board.slide`）：id 统一为规范形式，名称正常显示。

## 兼容性

- 场景文件格式升为 2：新增标注（`annotations`）、动滑轮（`PulleyDef.body`）、变力表达式（`ForceDef.expr`）。26.48 的文件（格式 1）打开时自动迁移；用 26.48 在 Windows 上保存的板块模型场景迁移后重算，结果指纹仍为 `bb1283491e1c…`。新格式的文件不保证能在 26.48 中正确打开。
- 26.48 的 14 个模板（默认参数）和 4 个手工场景的记录指纹与 26.48 逐位相同（`tests/golden.test.ts`）。
- 26.48 中有摩擦的接触面上发生单点碰撞的场景，26.49 会计入碰撞摩擦，结果与 26.48 不同；μ = 0 的碰撞不变。
- 26.48 的偏好设置（外观、有效数字、叠加显示、自动重算）首次启动时自动迁移。

## 已知限制

- 师生试用（手册 P0：至少 3 位老师、5 位学生）尚未进行；任务单和记录表已备好（`docs/reports/trial-26.49.md`），试用结果和据此的修正留待之后。
- 多个接触点同时发生的摩擦碰撞按光滑冲量计算（有警告）；只有单点碰撞计入摩擦。
- Moreau–Jean 时间步进精度降级：事件时刻不精确定位，接触力为近似值，碰撞、摩擦和数值损失合计记为“碰撞损失”，切换后不给公式对照。
- 记录仍按每个 Δt 完整保存，没有降采样存储；很长、很多物体的场景占用内存较多。
- 计算线程与界面之间用消息传递，不用 SharedArrayBuffer。
- 没有多选；界面缩放只改变文字和控件尺寸，不是整页缩放。
- PPTX 内嵌视频在 WPS 放映中能否播放尚未确认；未在 PowerPoint 中检查（本机未安装）。
- 网页版只在 Chromium 内核浏览器上验证过；不能直接双击 `index.html`（需 HTTP 服务器）。
