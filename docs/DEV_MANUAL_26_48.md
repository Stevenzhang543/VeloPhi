# Verity 26.48 开发手册

Verity（暂名）是一款面向物理专业学生和物理老师的物理仿真与教学引擎。用户搭场景、设参数、运行，随时暂停读出任意物体的物理量，并看到系统自动匹配的公式和代入结果，与仿真值并排显示误差。核心卖点是“物理上可验证的正确”：画面来自数值求解器，公式只做对照，误差公开。

本手册规定 26.48 做什么、怎么做、做到什么程度算完成。26.49 的计划见 `DEV_MANUAL_26_49.md`。前作 Nova_A 已暂停，本项目是独立的新仓库。

## 2. 不可妥协的原则如何落实

| 原则 | 落实方式 | 检查 |
| --- | --- | --- |
| 物理结果只来自求解器 | 核心只向外提供只读快照；渲染、公式、导出拿不到可写对象。公式层算出的值只放在对照栏，从不写回 | 类型上只读；测试断言渲染和公式求值前后记录数据的哈希不变 |
| 可复现 | IEEE-754 双精度；正弦、余弦、反正切等超越函数用移植的 fdlibm（不用 `Math.sin` 等，各浏览器末位不同）；不用随机数、不依赖墙钟；时间网格用 `k × Δt` 计算 | 同一场景重复运行、拖回重放、在 Chromium/Firefox/Node 中运行，记录数据的 SHA-256 一致 |
| 误差透明 | 每条对照显示公式值、仿真值、绝对与相对误差、判定和可能原因；求解器报告积分误差估计、约束投影修正量、事件定位精度 | 测试覆盖每类原因的出现条件 |
| 公式只在适用时出现 | 每条公式带适用条件；条件不满足时隐藏，或标注“近似失效” | 每条公式至少一个“套错”反例测试 |
| 单位与精度 | 内部全部 SI；角度存弧度、默认以度显示；有效数字可调（默认 4 位）；守恒漂移阈值见第 6 节 | 单位检查在公式加载时进行；漂移阈值进测试 |
| 公式库可扩展 | 公式是数据文件；运动识别器是插件；新增公式或识别器不改求解器 | 新增一条公式的测试只改公式层 |
| 面向教学 | 画面以矢量、标注、刻度为先；不做特效、脚本、音频 | — |

## 3. 关键技术决策

每条决策写明理由；后续变更要在这里追加记录。

**D1 平台：网页为主，同一份代码打包桌面版。** 学校电脑多是 Windows 且常被锁定，浏览器打开即用最省事；课堂断网或要导出大视频时用桌面版（Tauri 2，Windows 用 WebView2）。两者共用同一套前端和核心，结果一致。

**D2 维度：2D 起步，数据模型为 3D 留口。** 8 个验收场景都是平面问题，2D 让转动惯量、角速度是标量，求解器和公式都简单得多。场景文件带 `dimension: 2`，物理量在公式层以“分量 + 模”的方式描述，3D 以后作为新的求解器模块接入，不改公式与界面的接口。

**D3 核心语言：TypeScript，确定性数学自己实现。** 场景只有几个到几十个物体，难点在接触逻辑而不在算力；全部代码在浏览器、桌面 WebView 和 Node 测试里同一份运行，不需要 WASM 工具链。JavaScript 规定加减乘除与平方根按 IEEE-754 舍入，超越函数用 fdlibm 移植（复用 Nova_A 的 `stableTrig` 并补上反正切），即可逐位一致。若 3D 或大场景需要更快的核心，再评估 Rust/WASM（届时在本节追加决策）。

**D4 求解方法：事件驱动的混合求解（不是游戏引擎的时间步进）。** 现成游戏物理（Box2D、Rapier、Chipmunk、Jolt 等）用软约束和迭代冲量，不区分静摩擦与动摩擦系数，粘滑切换时刻被抹平在一个步长内，板块模型和传送带算不准；研究型库（MuJoCo、Drake、Simbody）用柔顺接触或连续化摩擦，无法表示真正的静摩擦粘着，也进不了浏览器。因此自研：
- 两次事件之间，接触模式固定，系统是光滑的常微分方程：每个接触点或闭合或张开，每个接触面或粘着或沿确定方向滑动；用拉格朗日乘子在加速度层求出加速度和约束力（小型稠密线性方程组，部分主元高斯消元）。
- 积分用自适应 Dormand–Prince 5(4)，默认相对容差 1×10⁻¹⁰、绝对容差 1×10⁻¹²，最大步长等于输出步长，步长对齐输出网格。
- 事件（碰撞、开始/停止滑动、共速、脱离接触、绳绷紧/松弛、接触点滑出边缘）用事件函数描述，用 Illinois 法从步首重新积分求根，时间精度 1×10⁻¹² s。
- 每个事件点重新确定接触模式：枚举候选模式（每个接触面最多“两点闭合/单点闭合/张开” × “粘着/正向滑/反向滑”），取第一个同时满足 λn ≥ 0、加速度可行、|λt| ≤ μs·Σλn 的组合，顺序固定，结果确定。
- 碰撞用冲量求解：牛顿恢复系数，所有正在闭合的点、已闭合的点（e=0）、铰链和杆一起解；碰撞瞬间不计摩擦冲量（模型简化，公式层写入原因）。
- 约束漂移超过 1×10⁻¹² m 时做一次质量加权投影（位置与速度），修正量计入误差报告。
- 极端情况（弹跳无限次、模式来回切换、静不定）有保护：碰撞闭合速度低于 1×10⁻⁶ m/s 视为完全非弹性接触；同一接触 1 ms 内切换超过 20 次即停止并报告；冗余约束行按主元容差丢弃并标注“静不定，分配不唯一”。

**D5 积分方法可切换，用于教学。** 默认“高精度（自适应 RK45 + 事件定位）”；另提供“固定步长 RK4”和“半隐式欧拉”，用来演示数值误差。低阶方法同样定位事件，但不承诺第 6 节的阈值，误差面板会显示实际漂移。

**D6 时间线：完整记录 + 确定性重算。** 求解器在每个输出时刻（默认 Δt = 1/600 s）记录完整状态（步长对齐网格，所以记录值就是求解器状态，不是插值），另记每段的接触模式和每个事件前后的状态。拖到任意时刻直接读记录；拖到两格之间时，从前一格用同一方法积分一步得到，结果仍确定。60 s、10 个物体约 30 MB。重算一遍的哈希必须等于首次记录。

**D7 能量账本。** 积分状态里附带累计量：每个接触面的摩擦生热与相对滑动距离、每个恒力与弹簧阻尼做的功；碰撞的动能损失在事件处记账。这样“摩擦生热 Q = f·s相对”“功能关系”可以用独立积分值核对。

**D8 公式库：数据文件 + 识别器插件。** 识别器读取场景结构、接触模式记录、事件和轨迹，输出“情境”（如斜面滑动、板块相对滑动、抛体、碰撞、单摆、弹簧振子、定轴转动、滚动、绳连接体）以及角色绑定。公式条目写在 JSON 中：编号、标题、LaTeX、适用条件、变量绑定、表达式、对照的仿真量、单位、条件不满足时的处理（隐藏或标注近似失效）、可能的误差原因。表达式用自带的小型解析器求值，加载时做量纲检查。新增公式只改数据文件；新增一类运动只加识别器。

**D9 渲染：Canvas 2D。** 教学画面以线条、箭头和文字为主，Canvas 2D 清晰、简单、可离线逐帧渲染视频；渲染函数输入是“快照 + 视图设置”，输出是像素。公式用 KaTeX（MIT）渲染，曲线用 uPlot（MIT）。

**D10 视频导出：WebCodecs 逐帧编码 + Mediabunny 封装 MP4。** 按时间逐帧离线渲染（不是录屏），时间准确，可选分辨率与帧率；优先 H.264（PowerPoint 可直接插入），不支持时退到 VP9/WebM。Mediabunny 是 MPL-2.0，原样使用、不改其源码，可用于闭源商用。不用 ffmpeg.wasm 的 GPL 构建。

**D11 场景文件：JSON（`.verity.json`）。** 带 `format`、`version`、`dimension`、`engine` 字段；全部数值为 SI；角度存弧度。读取时按版本顺序迁移，未知字段原样保留；保存时键顺序固定，便于比较。

**D12 Nova_A 的复用。**

| Nova_A 模块 | 结论 | 理由 |
| --- | --- | --- |
| 确定性三角函数 `stableTrig.ts` | 复用并扩展 | 已是 fdlibm 移植，补反正切即可 |
| 界面设计令牌、字体（Noto Sans SC、Nunito Sans、JetBrains Mono） | 复用 | 已验证的排版与深浅色方案 |
| Tauri 2 外壳、Windows 发布脚本、校验清单 | 改造后复用 | 流程成熟，只改产品名与产物 |
| 浏览器操作检查工具 `browserUserAudit` | 改造后复用 | 真实鼠标键盘检查界面 |
| Rust 物理核心 `nova_physics` | 不复用，重写 | 游戏用软约束与迭代冲量，单一摩擦系数，有穿透容差与休眠，目标是稳定不是精确 |
| 编辑器框架（Vue 组件、停靠布局、检查器） | 不整体复用，按需借鉴 | 体量大、绑定游戏概念；新编辑器只需少量面板 |

| 脚本、音频、动画、预制体、打包格式 | 不复用 | 不在本产品范围 |

## 5. 模块规格

### 5.1 场景模型

- **物体**：`particle`（质点，圆形碰撞半径，不转动）、`rigid`（圆、矩形、凸多边形，质量与转动惯量，转动惯量默认按均匀密度自动计算，可覆盖；可“锁定转动”）、`static`（地面、斜面、墙、传送带、任意凸多边形，不动）。
- **初始条件**：位置（质心）、角度、速度、角速度。
- **材料**：每个物体有默认 μs、μk、e；任意两物体之间可以设置“接触对”覆盖。未设置时取两者的较小值。界面在检查器里显示生效值。要求 μs ≥ μk，否则提示。
- **传送带**：静态矩形，带速 u（m/s），表面速度沿边界顺时针（u > 0 时上表面向右）。
- **连接**：绳（两端挂点，可经过若干定滑轮，滑轮有半径；张紧时为长度约束且张力 ≥ 0，松弛时无作用；默认长度为初始路径长度）、杆（无质量刚性距离约束，可拉可压）、弹簧（劲度系数、原长、阻尼系数）、铰链（物体与物体或物体与世界的点约束）、恒力（作用点、方向、大小）。
- **全局参数**：重力加速度矢量（默认 (0, −9.8) m/s²，可设 9.81 或 0 做俯视二维碰撞）、输出步长 Δt、积分方法、相对与绝对容差、仿真时长上限、能量零点高度。

### 5.2 求解器

- 状态：每个动态物体 (x, y, θ, vx, vy, ω)，加上能量账本累计量。
- 接触几何：每对可能接触的物体用连续的间隙函数（圆–圆、圆–多边形精确距离，多边形–多边形用分离轴的最大分离量）检测碰撞时刻；接触后生成接触面（最多两点），每点是“物体固连点（含半径）对物体固连面”或“点对点”，用解析的雅可比和速度二次项计算加速度层约束。
- 约束：铰链 2 行、杆 1 行、张紧绳 1 行（经滑轮时长度对端点的导数用两端自由段的单位方向）、闭合接触点 1 行、粘着接触面 1 行；滑动接触面的摩擦力 λt = −μk·sign(vt)·Σλn 并入法向列。
- 事件：碰撞（间隙由正变零）、脱离（λn 由正变零）、开始滑动（|λt| − μs·Σλn 由负变零）、停止滑动/共速（相对切向速度过零）、绳松弛（张力过零）、绳绷紧（路径长度达到绳长）、接触点到达接触面端点。每个事件记入事件表：类型、时刻、相关物体、前后状态。
- 输出：每格状态、每段模式、事件表、诊断（积分误差估计累计、投影修正量、模式切换次数、被丢弃的冗余约束）。

### 5.3 记录与时间线

- 计算在主线程分片进行（每帧最多 8 ms），先算后放；播放速度 0.1×–4×；单步为一个输出步长；可跳到上一个/下一个事件。
- 编辑任何参数都会让记录失效，回到 t = 0 重算。
- 拖动后的状态、重复运行的状态都用 SHA-256 校验。

### 5.4 读数与监视

- 点选物体显示：位置、位移、速度、加速度（含沿接触面的分量）、各个力（重力、每个接触面的法向力与摩擦力、张力、弹力、恒力）、合力、动量、动能（平动/转动）、重力势能、弹性势能、机械能、角度、角速度、角加速度、对质心及对指定点的角动量、转动惯量；接触面显示模式（粘着/滑动/张开）、相对速度、累计相对滑动、摩擦生热。
- 系统量：总动量、总动能、总机械能、能量账本（初始机械能 = 当前机械能 + 摩擦生热 + 碰撞损失 + 阻尼损失 − 外力做功）。
- 监视面板：任意物理量加入列表，实时曲线（可多条同图），光标跟随时间线。

### 5.5 公式自动匹配

- 识别器（26.48）：斜面上的滑动/静止、水平面滑动、板块相对滑动与共速、传送带加速段与共速、一维与二维碰撞、平抛与斜抛、单摆、弹簧振子、定轴转动、沿斜面滚动（纯滚动/打滑）、绳连接体与滑轮、守恒检查（机械能、动量、角动量）。
- 每条公式显示：LaTeX、适用条件（逐条显示满足与否）、代入式、公式值、仿真值、绝对误差、相对误差、判定（通过 / 近似 / 近似失效 / 超出阈值）、可能原因。
- 判定规则：精确公式且条件满足时按第 6 节阈值判定；近似公式显示理论偏差（例如小角度单摆周期的相对偏差约 θ₀²/16），θ₀ ≤ 5° 显示“近似成立”，5°–10° 显示“近似”，> 10° 标注“小角度近似失效”并同时给出精确周期（椭圆积分）。

### 5.6 渲染

- 世界坐标单位为米，可平移缩放，网格与比例尺；静态物体有阴影线，传送带有随时间移动的纹路，滑轮画轮子，绳画切线段，弹簧画折线。
- 矢量：速度、加速度、各个力（颜色区分，按比例尺或固定长度，可逐项开关）；轨迹；关键时刻（事件）在轨迹上标点并注明时刻与名称。

### 5.7 导出

- CSV：选定物理量、时间范围、采样间隔（输出步长的整数倍），表头含单位，UTF-8 带 BOM（Excel 正常显示中文）。
- 视频：时间范围、分辨率（1280×720、1920×1080）、帧率（30、60）、是否叠加时间与读数；逐帧渲染编码，显示进度，可取消。

### 5.8 编辑器

- 工具栏添加物体与连接；画布内拖动摆放、旋转；连接工具依次点两个物体。
- 检查器按物理含义分组，每个数值带单位；角度以度输入。
- 撤销/重做；新建、打开、保存、另存为；模板库（8 个验收场景及变体）。
- 界面语言中文为主，英文同步。

## 6. 误差阈值与依据

默认显示 4 位有效数字，显示分辨率约 5×10⁻⁵。阈值至少比它小一个数量级，保证“通过”的对照在屏幕上数字一致；同时比默认求解器容差（1×10⁻¹⁰）宽两到三个数量级，留出长时间积累的余量。所有阈值写进自动测试。

| 项目 | 阈值 | 依据 |
| --- | --- | --- |
| 精确公式与仿真值（条件满足） | 相对误差 ≤ 1×10⁻⁶；量值接近 0 时绝对误差 ≤ 1×10⁻⁹ × 该量的特征尺度 | 比显示分辨率小 50 倍；比求解器容差大 10⁴ 倍 |
| 事件时刻（共速、开始滑动、碰撞、脱离） | 与解析时刻相差 ≤ 1×10⁻⁹ s | 事件定位到 1×10⁻¹² s，余量给积分误差 |
| 机械能漂移（应守恒、默认积分器） | 每 10 s 仿真时间相对漂移 ≤ 1×10⁻⁸ | 课堂演示一般不超过 60 s，累计 ≤ 6×10⁻⁸，远低于显示分辨率 |
| 动量（孤立系统碰撞前后） | 相对变化 ≤ 1×10⁻¹² | 冲量等大反向，只剩舍入误差 |
| 角动量（无外力矩） | 相对漂移 ≤ 1×10⁻¹⁰ | 碰撞含转动时有约束投影 |
| 能量账本闭合（有摩擦、碰撞、恒力） | 相对不闭合 ≤ 1×10⁻⁸ | 账本与状态同一积分器积分 |
| 逐位复现 | 记录数据 SHA-256 完全相同 | 原则 2 |
| 低阶教学积分器 | 不设通过阈值，显示实测误差 | 用于讲数值误差 |

若基准测试表明某项阈值不合理，修改本表并在第 3 节追加理由，不得静默放宽。

## 7. 验收场景

每个场景必须：不写代码搭建；能在关键时刻暂停读数；公式与仿真误差在阈值内；数据可导出。每个场景有一个模板，并有自动测试用解析解核对。

| 场景 | 设置（模板默认值） | 关键时刻 | 自动核对 |
| --- | --- | --- | --- |
| 斜面滑块 | 30° 斜面，m = 2 kg；无摩擦与 μ = 0.2 两个变体；另有 μs 足够大时静止的变体 | 释放、到达底端 | a = g(sinθ − μk cosθ)；f = μk N；N = mg cosθ；功能关系 mgh = ½mv² + Q；静止时 f = mg sinθ ≤ μs N |
| 板块模型 | 木板 M = 2 kg 在地面（μ₂ = 0.1）上，滑块 m = 1 kg 以 4 m/s 滑上木板（μ₁ = 0.4） | 共速、一起减速、停止 | 两物体各自加速度、共速时刻与速度、相对滑动距离、Q = μ₁mg·s相对、摩擦力方向 |
| 传送带 | 水平带速 2 m/s 与 37° 倾斜带两个变体，μ = 0.5 | 共速、到达端点 | 加速段时间与位移、共速后的状态（倾斜时判断能否一起运动）、摩擦生热 Q = f·s相对 |
| 碰撞 | 一维弹性、非弹性（e = 0.5）、完全非弹性；二维斜碰（g = 0 俯视） | 碰撞瞬间 | 动量守恒、恢复系数、动能损失 ΔEk = ½·m₁m₂/(m₁+m₂)·(1−e²)·v相对² |
| 平抛与斜抛 | v₀ = 5 m/s 水平；v₀ = 10 m/s、45° | 最高点、落地 | 分量随时间、射程、最高点、飞行时间 |
| 单摆与弹簧振子 | L = 1 m，θ₀ = 5° 与 30°；k = 50 N/m，m = 0.5 kg | 一个周期 | T = 2π√(L/g)（大角度标注失效并给精确周期）、T = 2π√(m/k)、能量转换与守恒 |

| 连接体 | 桌面滑块 m₁ = 2 kg（μ = 0.2）经桌边定滑轮连接悬挂物 m₂ = 1 kg | 释放、悬挂物落地 | 整体法与隔离法的加速度与张力一致：a = (m₂g − μm₁g)/(m₁+m₂)，T = m₁(a + μg) |
