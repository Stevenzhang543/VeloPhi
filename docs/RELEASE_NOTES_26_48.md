# Verity 26.48 发布说明

发布日期：2026-10-24 · 版本 26.48.0 · 首个版本

Verity（暂名）是面向物理专业学生和物理老师的力学仿真与教学引擎：搭场景、设参数、运行，随时暂停读数，并由系统识别典型情形、给出带适用条件的公式，代入后与仿真结果并排显示误差。前作 Nova_A 已暂停，Verity 是独立的新仓库，只复用了 Nova_A 的确定性三角函数思路、设计令牌与字体、Tauri 外壳和发布流程。

## 本版内容

**场景搭建（P0）** 质点小球、矩形物块、圆柱、多边形楔块；地面、斜面、墙、传送带、定滑轮；轻绳（可绕多个滑轮）、轻杆、弹簧（可带阻尼）、铰链、恒力。放置时自动贴合下方表面。撤销/重做（200 步）、复制、删除。场景文件 `.verity.json`（固定键序、双精度原值、带版本号与迁移入口，未知字段保留）。

**参数（P0）** 全部参数可编辑，国际单位并标注单位；角度以度显示、以弧度保存。全局重力、记录步长 Δt、积分方法（Dormand–Prince 5(4) 自适应 / RK4 / 半隐式欧拉）、容差、时长、势能零点；有效数字 3–12 位可调（默认 4 位）。接触对可单独设置摩擦因数与恢复系数。

**求解器（P0）** 事件驱动的混合求解：每个阶段接触点的开闭、黏滞/滑动及方向、绳的松紧固定，约束力由加速度级方程精确解出（库仑摩擦直接并入法向行，完全主元消去识别冗余支撑）；阶段切换由事件函数定位（碰撞、分离、离开边缘、开始滑动、共速、绳松弛/绷紧），定位精度约 10⁻¹² s；碰撞按牛顿恢复系数同时求解所有接触（光滑冲量），慢于 10⁻⁵ m/s 的碰撞视为完全非弹性以消除芝诺效应；约束漂移超过 10⁻¹² 时按质量加权投影修正并记录修正量。

**时间线（P0）** 播放、暂停、逐帧、变速（0.05×–2×）、循环、拖动、跳到上一个/下一个事件。每个 Δt 记录完整状态，回到同一帧逐位一致；帧间任意时刻由该阶段的一个积分步精确给出。

**暂停与监视（P0）** 点选运动物体即列出此刻全部读数（位置、速度、加速度、角速度、角加速度、动量、动能、势能、对质心角动量、所受支持力与摩擦力）；监视列表可加入任意观测量（接触力、绳张力、弹力、铰链力、相对滑动路程、摩擦生热、系统能量与动量、能量账本）；x‑t / v‑t / a‑t、能量、受力曲线，同单位合并，事件时刻以虚线标出，点击曲线跳转。

**公式自动匹配（P0）** 识别器从记录中识别情形：斜面（含倾斜传送带，按相对滑动方向）、水平面与传送带、板块模型（滑动阶段与共速后）、两体碰撞（正碰/斜碰）、与固定面碰撞、抛体、单摆、弹簧振子、定轴转动、斜面滚动（纯滚动/边滚边滑）、小球撞击铰接物体、桌面—滑轮连接体、阿特伍德机、能量账本、孤立系统动量。公式库是数据（`src/formula/library.ts`，16 类情形 68 条），每条带适用条件、符号式、代入式、单位与量纲检查。卡片显示理论值、仿真值、绝对与相对误差、判定（一致 / 偏差超限 / 近似成立 / 近似 / 近似失效 / 不适用及原因）。

**教学化显示（P1）** 速度、加速度矢量与数值；受力分析（重力、各接触点支持力、摩擦力、张力、弹力、铰链力、外力，带大小）；质心轨迹；关键时刻标注（“物块–木板 相对静止（共速） t = 0.907 s”等）。浅色（适合投影）与深色外观。

**导出（P1）** CSV：任选观测量、时间段与抽帧间隔，双精度原值，表头带场景、Δt、积分设置与结果指纹，UTF‑8 BOM 便于 Excel 打开。视频：1080p/720p、30/60 帧、0.1×–2× 速度、可叠加监视数值；每帧取该时刻的精确状态；有 H.264 编码器时输出 MP4，否则 WebM（VP9）。

**模板（P1）** 14 个经典模型：斜面滑块、板块模型、水平传送带、倾斜传送带、一维碰撞、二维斜碰、抛体、单摆、弹簧振子、定轴转动细杆、斜面上的圆柱、小球碰撞细杆、阿特伍德机、桌面—滑轮连接体。参数可在创建前修改。

## 已知限制

- 只有二维；碰撞冲量不计摩擦（光滑冲量），刚体间的摩擦碰撞（如斜着打到地面的旋转圆盘）在冲击瞬间不产生切向冲量。
- 接触面是平面多边形与圆；没有凹形状、曲面轨道和细杆—物体接触以外的线段碰撞体。
- 仿真在界面线程中计算：复杂场景（很多物体、很长时长）计算期间界面会停顿，超过 60 s 自动停止并保留已算部分。Web Worker 计划在 26.49。
- 公式识别覆盖手册列出的情形；自己搭的复杂场景可能只显示能量账本和部分公式。
- 绳只能绕固定滑轮；动滑轮、可变力 F(t)、课件导出见 26.49 手册。
- 网页版只在 Chromium 内核浏览器上验证过；不能直接双击 `index.html`（需 HTTP 服务器）。
