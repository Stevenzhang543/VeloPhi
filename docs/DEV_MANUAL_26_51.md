# Verity 26.51 开发手册

26.51 在 26.50 的地基（无限时长、三语言、公式详情、Rust 核心）上做三件事：**按使用者的知识水平组织公式**——知识难度分级（中国课标与 IB 两套体系）、更多分级公式、更清楚的解题过程、内置学习手册；**提高自由度**——无极调节的编辑（只在贴近其他物体时吸附）、新连接件、场与阻力、运行中编辑与分支；**补齐 26.50 的遗留问题**。另换新图标。原则、阈值与决策 D1–D33 继续有效。

**范围修订（2026-10-25，维护者确认）：** 维护者在 26.50 发布后提出 6 项要求（U1–U6，见第 2 节），优先于原手册的课堂类功能。本版做：U1–U6 全部、原手册的物理与公式核心（场与阻力、新连接件、多点摩擦碰撞、运行中编辑与分支、分级公式库、自定义量）和 26.50 遗留。顺延到 26.52：凹形与复合体、切割、链节绳、辛积分、原生桌面引擎、自定义公式卡、触屏与交互白板（D42）、无障碍（D43）、题目模式与题目包（D40）、分享、教学表示、插件接口、滚动阻力、有心力、滑轨限位与马达力矩上限。

## 4. 本版新增决策

**D34 分支而不是覆盖。** 运行中编辑不修改已算的记录：在时刻 t 的精确状态上应用修改，生成新的场景快照（初始条件 = t 时的状态 + 修改），作为子分支从 t 继续计算。分支保存在场景文件中（`branches`：父分支、分支时刻、修改列表），任何分支都可以从头重现（父分支重算到 t，再应用修改）。曲线与读数可叠加显示两个分支，用于“如果 μ 变大会怎样”的对比。

**D35 复合体与凹形。**（顺延 26.52） 凹多边形用确定性的耳切 + 合并算法分解为凸块（同一输入总得到同一分解）；复合体是一个刚体、多个碰撞形状；质量属性按各块面积加权与平行轴定理计算。接触特征按块生成，同一复合体内部不检测碰撞。

**D36 新连接件进入模式框架。** 焊接、滑轨、马达、齿轮比都是等式约束（行），进入现有的加速度层约束求解；滑轨限位与马达力矩上限是不等式（与接触同样处理：开/闭、事件定位）；链节绳由小刚体与铰链组成，不另写求解器。

**D37 多点摩擦碰撞。** 冲量层的线性互补问题：未知量为各接触点的法向与切向冲量，约束为非穿入、库仑锥（二维中为两个不等式）与互补条件；枚举有限个接触状态组合（与模式枚举同样的确定顺序），对每个候选解检验互补条件和 Stronge 能量条件（总动能不增加），取第一个可行解；全部不可行时退回光滑冲量并警告。接触点上限 8 个（2⁸×3⁸ 以内的枚举，超过则用 Moreau–Jean 后备）。

**D38 辛积分选项。**（顺延 26.52） 新增积分方法“Gauss–Legendre 4 阶（辛）”，定步长、隐式（不动点迭代到机器精度，固定迭代次数以保证确定性）；只在无耗散、无接触切换的阶段使用，阶段有事件时仍精确定位。用于行星轨道和长时间振动演示，能量误差有界不漂移。

**D39 自定义公式的安全与校验。**（本版只用于自定义量；自定义公式卡顺延 26.52） 自定义公式用公式层同一个表达式语言（D14 扩展），只能引用观测量与常数，不能执行代码；保存时做量纲检查（与内置公式相同的检查器）；在题目与课件中与内置公式同等显示，但标明“自定义”。

**D40 题目包格式。**（顺延 26.52） `.verity-problem.json`：场景（格式 4）+ 题目（题干、问题、答案、容差、提示、语言）+ 可选的预期公式卡；答案在文件中明文保存（教学用途，不做防作弊）；题目中的数值可以绑定场景参数，改参数后答案按公式重算。

**D41 场景格式 4。** 26.50 已用格式 3（不限时长 `duration: null`、`stopAt`、`legacyDuration`），本版升为 4。新增：新连接件（weld、slider、motor、gear、damper，弹簧的 k₃）、场与阻力参数（`settings.gravitation`、物体的 `drag`）、分支（`branches`、`settings.startTime`）、自定义量（`customQuantities`）。格式 1/2/3 → 4 迁移只补默认值，`legacyDuration` 与 `stopAt` 原样保留。

**D42 输入层统一为 Pointer Events。**（顺延 26.52） 鼠标、触摸、笔走同一套处理；手势识别（双指缩放平移、长按）在画布层完成；所有可点击元素在触屏模式下放大到 44 px。

**D43 无障碍描述层。**（顺延 26.52） 画布旁维护一个对屏幕阅读器可见、对视觉隐藏的描述树：场景摘要（物体数、连接、当前时刻）、选中物体的读数（显示单位）、最近事件；事件发生时通过 `aria-live` 简短播报（可关）。描述文本走三语言表。

**D44 知识难度：一条公式两个级别标签。** 每条公式标注两套级别：`cn`（初中 / 高中必修 / 高中选择性必修 / 大学 / 更高）与 `ib`（MYP / SL / HL / 大学 / 更高），两者映射到同一序数（初中=MYP=1，高中=SL=2，HL=3，大学=4，更高=5；中国“高中选择性必修”算 2）。设置中的课程体系决定读哪一套标签、显示哪套级别名称；知识水平决定上限。超过上限的公式不删除：折叠为一行“还有 N 条更高级的公式”，可展开；识别器与对照照常计算（只影响显示），因此切换级别不重算。默认：简体中文界面为“中国课标 · 高中”，英文与德文界面为“IB · DP SL”。导出（报告、课件）使用同一筛选，可在导出对话框改为“全部公式”。

**D45 解题过程：结构化而不是一行代入式。** `solve.ts` 生成的不再只是“代入—化简”的一列式子，而是结构：已知量（符号、数值、显示单位、来源：场景参数 / 阶段初的状态 / 上一条公式的结果）、所求量、选用的公式（及其编号）、单位换算（显示单位不是国际单位时单列一步）、代入式、逐步计算（每一步一句说明：“先算括号内”“分子”“分母”“开方”等，由表达式树的结构生成）、答（带单位、按有效数字）、与仿真对照（绝对、相对误差与误差来源）。符号与数值配色一致：已知量各分配一种颜色（色盲安全色板），符号式、代入式与已知量表使用同一颜色（KaTeX `\textcolor`）。卡片上显示紧凑版（已知量一行 + 着色代入式 + 结果），可就地展开逐步计算；详情面板显示完整版；格式为中文“已知 / 求 / 解 / 答”，英文“Given / Find / Solution / Answer”，德文“Gegeben / Gesucht / Lösung / Antwort”。

**D46 学习手册：内容是数据，页面由数据生成。** 手册由三部分数据组成：主题（力与运动、相互作用与摩擦、能量与功、动量与碰撞、圆周运动、振动、转动、万有引力与轨道、阻力，每个主题一篇三语原理讲解）、公式（公式库本身：标题、符号式、符号表、适用条件、级别、推导）、示例（哪些模板会触发该公式，由识别器对模板运行得到并在构建时缓存）。页面：左侧主题目录与搜索，右侧条目；按当前知识水平筛选（可切换“显示全部级别”）；“打开示例”载入模板并定位到相应时刻。公式卡片的“在手册中查看”直接跳到条目。

**D47 无极调节与物体吸附。** 所有几何编辑（移动、缩放、旋转、顶点、连接点、标注）默认连续：坐标不取整、不落网格。吸附只在两种情况下出现：(1) **物体吸附**（默认开）：被拖动物体的边、顶点、圆周与其他物体的面、顶点、圆周的距离小于 6 px（屏幕）时，吸到“刚好接触”的位置（面贴面、点贴面、圆与面相切、圆与圆相切）；连接点吸到物体中心、顶点与滑轮切点；旋转在接近 0°、90° 或附近表面的倾角（±1.5°）时吸附；(2) **网格吸附**（可选，默认关）。吸附有滞后：进入 6 px 吸附，指针再离开 14 px 才脱开，形成“阻尼”手感；吸附时显示参考线与接触点标记。按住 Alt 临时关闭全部吸附。数值框：拖动标签连续调节（Shift 细调 ×0.1，Ctrl 粗调 ×10），滚轮调节，输入值不取整。

**D48 新图标。** 主题为“抽象物理轨迹”：一条抛物线轨迹与沿轨迹等时间间隔的频闪点（体现 Verity 的频闪与“可验证”），深色渐变底、圆角方形；矢量源文件 `assets/icon.svg`，构建时生成 1024 px PNG，再用 `tauri icon` 生成全部尺寸；界面标志、网页图标与图标同源。

**D49 双引擎继续同步（修订 D31）。** D31 原定 26.51 起新物理只在 Rust 实现。由于逐位对照（D30）是目前最有效的验证手段，且 TypeScript 引擎仍承担后备、参数扫描与界面线程重算，本版的新物理两边都实现并纳入 `parity.mjs`；冻结 TypeScript 引擎推迟到 26.52 评估。

**D50 场与阻力。** 重力是任意方向的向量（界面以大小 + 方向角编辑）。万有引力：场景开关 + 引力常量 G（默认 6.674×10⁻¹¹，可改为教学用的 G = 1 等），作用在每一对有质量的物体之间（静态物体的质量参与吸引但自身不动），F = Gm₁m₂/r²，沿质心连线；引力势能 −Gm₁m₂/r 计入能量账本。阻力：每个物体可设线性系数 b（N·s/m）与二次系数 c（N·s²/m²），F = −(b + c|v|)v 作用于质心；耗散计入账本的“阻尼与阻力耗散”项。为保持 26.50 场景的指纹，状态向量布局不变（阻力耗散并入已有的阻尼项）。

**D51 新连接件的约束形式。** 焊接：铰链的两行 + 相对角度一行；滑轨：垂直于轴的相对位移一行 + 相对角度一行（轴随 A 物体转动；B 可选“允许转动”）；齿轮/皮带：ω_A + r·ω_B = 0 一行（皮带同向时 r 取负）；恒转速马达：相对角速度 = ω₀ 一行（开始时速度投影一次到目标转速，事件表注明），恒力矩马达：施加力偶；马达与皮带做的功计入“电机做功”；阻尼器：k = 0 的弹簧（画成阻尼筒）；非线性弹簧：F = −k x − k₃x³，弹性势能 ½kx² + ¼k₃x⁴。

**D52 运行中编辑与分支（D34 的实现方式）。** 分支从一个记录帧时刻 t 开始：取 t 的精确状态（位置、速度、能量账本、时间），应用用户的修改，形成子分支的初始条件；子分支的场景另存 `settings.startTime = t` 与账本初值，从 t 起计算。主分支在 [0, t] 的记录直接复用。场景文件保存分支树（父分支、t、修改后的场景），任一分支都能从头重现。时间线标出分支点；曲线可叠加显示另一分支（虚线）。

**偏差与原因：**

1. **D50 万有引力的近距离软化。** 两物体距离小于两者包围圆半径之和 R 时，引力改为 F = Gm₁m₂·d/R³（线性减小到 0），势能相应改为连续的二次形式。原因：随机场景中齿轮连接、互不碰撞的两个物体可以重叠，1/r² 在 r → 0 时使步长无穷小、运行挂起。R 之外与手册一致；轨道模板与开普勒、活力公式的对照不受影响。
2. **D37 求解顺序与上限。** 手册写的是“枚举后取第一个满足互补与 Stronge 能量条件的解；全部不可行时退回光滑冲量并警告；超过 8 点用 Moreau–Jean”。实现：只在光滑求解后有 ≥ 2 个作用点且摩擦确实起作用时进入；依次尝试牛顿律（目标 −e·vₙ⁻）、泊松律（e = 0 的压缩解，再把每个接触的冲量乘以 1 + e，等式约束重新求解）、完全非弹性（加警告）；全部不可行时退回光滑冲量（警告）。超过 8 个摩擦点或枚举超过 3⁸ 次直接退回光滑冲量（不切换 Moreau–Jean，避免一次碰撞改变整段记录的精度等级）。另加一条保护：光滑求解在多点同时碰撞时若使动能增加，改按完全非弹性重算并警告（`warn.multiImpactPlastic`）。原因：牛顿律在墙角等过约束布置中常常无解，随机测试中只有牛顿律时约 10% 的多点碰撞要警告，加入泊松律后降到 1.7%。
3. **D52 分支的时间线。** 手册写的是“主分支 [0, t] 的记录直接复用”。实现：分支是一个完整的新场景（初始条件为 t 时刻的精确状态，`settings.startTime = t` 只让变力看到绝对时间，`settings.startLedger` 延续能量账本），自己的记录从 0 开始，界面显示时加上 t（时间线、曲线、事件、读数、CSV 都显示绝对时间）；父分支的记录不拼接进分支的时间线，曲线叠加时父分支在界面线程中用 TypeScript 重算并缓存。原因：拼接需要两段记录共享帧布局、检查点和指纹（分支可以增删物体），代价大；独立场景让每个分支都能从文件单独重算并得到相同指纹，满足验收中“可从头重现”。
4. **26.50 遗留的实现方式。** (1) 重算放在专门的重算线程（`src/worker/rebuild.worker.ts`，与计算线程分开，计算线程在运行结束后关闭），由播放（下一块）与曲线（视野中的块）预取；同步路径保留为后备。(3) “到达滑轮”的阈值为绳段 1 mm。(4) 近似静止阈值：全部速度与加速度 ≤ 10⁻⁶ 持续 1 s（记录帧），只在不限时长且没有变力表达式、没有运行中的传送带时启用。(5) 自检由发布脚本以 `--selftest` 启动构建出的桌面程序完成（`scripts/webview-selfcheck.ps1`、`src/app/selfCheck.ts`）。
5. **步内决定的停止。** 永久静止、近似静止、到达滑轮改为在下一次循环顶部结束运行（先写该块的检查点），两个引擎一致。原因：在步内直接结束时，若最后一帧恰好是新块的第一帧，前一块不会被关闭，Rust 的增量写入因此越界（近似静止的 1 s 持续时间正好等于块长，使这种情况变得常见）。
6. **阿特伍德机的黄金指纹。** 有限时长（26.48 的时长）内轻物块到达滑轮，计算在 t ≈ 0.958 s 停止，指纹由 `c80279a5…` 变为 `c9210c01…`；事件之前的帧逐位不变（新的事件函数在触发前不影响积分）。其他 26.48 / 26.49 模板与手工场景指纹不变。
