# Verity 26.51 开发手册

26.51 在 26.50 的地基（无限时长、三语言、公式详情、Rust 核心）上做三件事：提高自由度——让用户能搭出任意的二维力学场景、在任意时刻修改并继续；扩展引擎与公式库——覆盖高中到大学一年级力学的主要情形；补齐课堂使用的短板——触屏与交互白板、无障碍、题目模式、分享。新的物理功能只在 Rust 引擎中实现（D31）。原则、阈值与决策 D1–D33 继续有效。

## 2. 版本目标

| 优先级 | 功能 | 要求 |
| --- | --- | --- |
| P0 | 运行中编辑与分支 | 暂停在任意时刻 t，修改任何物体/连接件/参数（位置、速度、质量、μ、力、加连接件、删物体），从 t 的状态继续算（“从此刻分支”）；原记录保留为对照分支，可切换和叠加显示；时间线显示分支点 |
| P0 | 任意形状与复合体 | 凹多边形（自动凸分解为复合刚体，质心与转动惯量按整体计算）、圆角矩形、由多个形状焊接的复合体；“切割”工具把物体沿直线分成两个；形状编辑沿用 26.49 的顶点手柄 |
| P0 | 连接件扩展 | 焊接（固定连接）、滑轨（平移副，可限位）、马达（恒角速度或恒力矩，可限力矩）、齿轮/皮带传动比、带质量的绳（链节）、非线性弹簧（F = k₁x + k₃x³ 或表达式）、阻尼器 |
| P0 | 场与阻力 | 任意方向的匀强重力场；万有引力（物体之间，用于天体与卫星轨道）；空气阻力（线性 bv 与二次 cv²，可按物体设置）；滚动阻力；有心力（表达式 F(r)） |
| P0 | 引擎升级（Rust） | 多点同时摩擦碰撞（以冲量为未知量的线性互补问题，按 Stronge 能量条件筛选解，保证不增能）；长时间守恒系统可选辛积分（Gauss–Legendre 隐式 RK，能量误差不随时间增长，用于轨道与无阻尼振动）；接触多时的性能（宽相加空间哈希）；原生桌面引擎评估：Tauri 后端直接调用 `verity-core`（与 WASM 同源），若比 WASM 快 1.5 倍以上则桌面版默认用原生 |
| P0 | 公式库扩展 | 新增情形与公式（每条带三语推导，D28）：阻力下的运动与终端速度、水平面圆周（圆锥摆、转盘、弯道倾角）、竖直圆轨道（轨道内侧/外侧、环形过山车）、万有引力与轨道（开普勒三定律、活力公式、第一宇宙速度、变轨）、阻尼与受迫振动（共振曲线）、耦合振动（简正模式）、一般二维弹性/非弹性碰撞、角动量守恒（转动碰撞、收臂转动）、变力做功与冲量（F–x、F–t 图面积）、滑轨与连接体、复合体转动惯量（平行轴定理） |
| P0 | 自定义量与自定义公式 | 监视与曲线支持表达式量（如 `ek(b1)+ep(b1)`、`x(b2)-x(b1)`）；教师可写自定义公式卡（表达式 + 变量绑定 + 适用条件），与内置卡片一样代入、对照、给出代入求解过程 |
| P1 | 触屏与交互白板 | 改用 Pointer Events：单指拖动/创建、双指缩放平移、长按代替右键、笔压不需要；触控目标 ≥ 44 px 的“触屏模式”；在 1920×1080 白板上整页可操作 |
| P1 | 无障碍 | 键盘完成所有操作（Tab 焦点、方向键移动选中物体、快捷键表）；屏幕阅读器描述层：场景摘要、选中物体读数、事件发生时的简短播报；色盲安全配色（矢量与曲线颜色另加线型区分）；高对比度 |
| P1 | 题目模式 | 题目卡：题干（三语言或单语）、配图来自场景、若干问题（数值答案带单位与容差、选择题），学生先作答再运行揭晓；教师在编辑器中创建题目、导出题目包（场景 + 题目）；内置 30 道按教材章节组织的例题 |
| P1 | 分享 | 场景/题目压缩后编码为链接（网页版打开即加载）和二维码；桌面版可“导出分享文件” |
| P1 | 教学表示 | 受力分析图（单个物体的隔离体图，按教材画法，可导出）；打点计时器纸带（固定周期打点，可测相邻间距与逐差法求加速度）；v–t 图下的面积着色（= 位移） |
| P2 | 电学插件准备 | 定义插件接口：插件提供新的场景元素、Rust 求解模块（与力学同一时间轴）、公式与情形、三语文本；26.51 只做接口与一个示例插件（恒定电流的电阻网络），不对用户开放 |

**26.50 遗留（并入本版）：** (1) 被释放的块改在计算线程中重算（WASM），界面只接收结果；(2) 德文数字可选小数逗号，导出对话框可单独选择语言；(3) “到达滑轮”事件：物块或绳端到达滑轮时作为事件定位并停止（取代 26.50 中的“步长过小”）；(4) 渐近静止的停止判据（速度与加速度低于阈值并持续一段时间后，按“近似静止”停止，指纹注明）；(5) WebView2 中 WASM 与 TS 的对照纳入每次发布的自动检查。

## 3. 不做

三维；流体（SPH）与软体；光学；AI 生成场景；账户与云端班级管理（题目包以文件和链接分享）。

## 4. 本版新增决策

**D34 分支而不是覆盖。** 运行中编辑不修改已算的记录：在时刻 t 的精确状态上应用修改，生成新的场景快照（初始条件 = t 时的状态 + 修改），作为子分支从 t 继续计算。分支保存在场景文件中（`branches`：父分支、分支时刻、修改列表），任何分支都可以从头重现（父分支重算到 t，再应用修改）。曲线与读数可叠加显示两个分支，用于“如果 μ 变大会怎样”的对比。

**D35 复合体与凹形。** 凹多边形用确定性的耳切 + 合并算法分解为凸块（同一输入总得到同一分解）；复合体是一个刚体、多个碰撞形状；质量属性按各块面积加权与平行轴定理计算。接触特征按块生成，同一复合体内部不检测碰撞。

**D36 新连接件进入模式框架。** 焊接、滑轨、马达、齿轮比都是等式约束（行），进入现有的加速度层约束求解；滑轨限位与马达力矩上限是不等式（与接触同样处理：开/闭、事件定位）；链节绳由小刚体与铰链组成，不另写求解器。

**D37 多点摩擦碰撞。** 冲量层的线性互补问题：未知量为各接触点的法向与切向冲量，约束为非穿入、库仑锥（二维中为两个不等式）与互补条件；枚举有限个接触状态组合（与模式枚举同样的确定顺序），对每个候选解检验互补条件和 Stronge 能量条件（总动能不增加），取第一个可行解；全部不可行时退回光滑冲量并警告。接触点上限 8 个（2⁸×3⁸ 以内的枚举，超过则用 Moreau–Jean 后备）。

**D38 辛积分选项。** 新增积分方法“Gauss–Legendre 4 阶（辛）”，定步长、隐式（不动点迭代到机器精度，固定迭代次数以保证确定性）；只在无耗散、无接触切换的阶段使用，阶段有事件时仍精确定位。用于行星轨道和长时间振动演示，能量误差有界不漂移。

**D39 自定义公式的安全与校验。** 自定义公式用公式层同一个表达式语言（D14 扩展），只能引用观测量与常数，不能执行代码；保存时做量纲检查（与内置公式相同的检查器）；在题目与课件中与内置公式同等显示，但标明“自定义”。

**D40 题目包格式。** `.verity-problem.json`：场景（格式 4）+ 题目（题干、问题、答案、容差、提示、语言）+ 可选的预期公式卡；答案在文件中明文保存（教学用途，不做防作弊）；题目中的数值可以绑定场景参数，改参数后答案按公式重算。

**D41 场景格式 4。** 26.50 已用格式 3（不限时长 `duration: null`、`stopAt`、`legacyDuration`），本版升为 4。新增：复合体与凹形、新连接件、场与阻力参数、分支、题目引用、自定义量与自定义公式。格式 1/2/3 → 4 迁移只补默认值，`legacyDuration` 与 `stopAt` 原样保留。

**D42 输入层统一为 Pointer Events。** 鼠标、触摸、笔走同一套处理；手势识别（双指缩放平移、长按）在画布层完成；所有可点击元素在触屏模式下放大到 44 px。

**D43 无障碍描述层。** 画布旁维护一个对屏幕阅读器可见、对视觉隐藏的描述树：场景摘要（物体数、连接、当前时刻）、选中物体的读数（显示单位）、最近事件；事件发生时通过 `aria-live` 简短播报（可关）。描述文本走三语言表。

## 6. 验收

| 项 | 标准 |
| --- | --- |
| 分支 | 在 t = 0.5 s 改 μ 后继续；两条分支都可从头重现（指纹一致）；叠加曲线正确 |
| 凹形与复合体 | L 形、U 形物体在地面上倒下、互相卡住，质心与转动惯量与解析值一致（≤ 10⁻¹²）；同一输入的凸分解逐位相同 |
| 新连接件 | 马达驱动的轮子匀速、滑轨上的物块只沿轨道运动、齿轮比 2:1 的角速度关系 ≤ 10⁻⁹ |
| 阻力 | 小球下落的终端速度 √(mg/c)（二次阻力）与解析式一致；线性阻力 v(t) 解析式 ≤ 10⁻⁸ |
| 万有引力 | 圆轨道周期与开普勒第三定律 ≤ 10⁻⁹（辛积分 100 周后能量误差有界）；椭圆轨道近日点/远日点速度满足活力公式 |
| 多点摩擦碰撞 | 随机 10000 次多点碰撞动能不增加；方块平落到粗糙地面（两点同时）结果对称 |
| 公式库 | 新增情形每种至少 1 个模板与正反例；全部新公式有三语推导，代入求解与卡片一致 |
| 触屏与无障碍 | 在 1920×1080 触屏（或 Chromium 触摸仿真）中完成教师任务单全部操作；只用键盘完成同样操作；屏幕阅读器（NVDA）读出场景摘要与选中物体读数 |
| 题目模式 | 内置 30 道题全部可作答、揭晓、导出题目包；改参数后答案自动更新 |
| 性能 | 26.50 的速度不下降；100 个物体的堆叠场景在 Moreau–Jean 后备下实时以上 |

## 7. 测试与发布
