## C 物理（D58–D61、D35）

- 滑轨限位与马达力矩上限（单边约束与“打滑/锁定”状态，事件定位，限位碰撞按 e）；滚动阻力（滚动静止/滚动状态，耗散计入摩擦生热）；有心力（幂律、软化、场势能）；Gauss–Legendre 辛积分；状态非有限时停止（`err.stateNotFinite`）。

- 情形识别：阶段签名含接触面法向；有滚动阻力时不识别纯滚动。
- 新模板 4 个（共 35 个）。
- TypeScript 与 Rust 同步实现；`scripts/parity.mjs` 新增 `--random2652`（限位、马达、滚动阻力、有心力、辛积分、凹形与复合体、凹形地形）。检查点格式 2。
