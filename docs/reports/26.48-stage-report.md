# 26.48 阶段报告

日期：2026-10-24。按 `docs/DEV_MANUAL_26_48.md` 第 10 节的阶段顺序记录完成情况、验证方式和偏离。

## 阶段 1 核心：数学、模型、求解器

- `src/core/math`：fdlibm 移植的 sin/cos/tan/atan/atan2/asin/acos/exp/log/pow（整数次幂用平方乘），向量与完全主元稠密求解。
- `src/core/solver`：模型编译（形状、质量性质、多边形移到质心、接触对材料）；运动学（点—面、点—点含顶点锥、绳穿过带符号半径的滑轮、杆、铰链），每条约束给出值、雅可比、速度乘积项；模式求解（行装配、滑动摩擦并入法向行）；模式枚举（闭合优先、黏滞优先，完整检查互补条件）；冲击（多点同时牛顿恢复，主动集枚举，芝诺阈值）；Dormand–Prince 5(4)、RK4、半隐式欧拉；事件函数与 Illinois 定位；质量加权投影；驱动与记录（网格帧、阶段、事件前后状态、SHA-256）。
- 验证：`tests/kinematics.test.ts` 用有限差分校验全部雅可比与速度乘积项（30 多个接触特征、两轮滑轮绳、杆、铰链）。

偏离与说明：
- 碰撞冲量光滑（不含摩擦冲量），写入已知限制。
- 事件迟滞的再武装规则在测试中发现问题后改为“已分离的探针不加迟滞”：否则弹跳越来越低的小球每次多下落 ε，会持续获得能量（`tests/robustness.test.ts` 覆盖）。
- 步长控制原用 `Math.pow`，在 Chromium 与 Node 中末位不同，导致阿特伍德机的记录指纹不同；改为确定性 `pow` 后 14/14 一致（`scripts/check-browser-hashes.cjs`）。
