## 第一次构建

在第 5 步（测试）失败 1 项：`engine.test.ts` › 模板“滑轨限位”的 WebAssembly 与 TypeScript 结果比较（56 个文件通过，669 / 670 项）。两个原因：

1. TypeScript 写出的警告参数顺序是 `{t, reason}`，WebAssembly 传输层按键名排序后是 `{reason, t}`，JSON 字符串比较不同。TypeScript 一侧改为按字母顺序书写。
2. 更重要的是物理问题：滑块压在限位上时出现 408 个限位事件，最后因“事件过密”退回 Moreau–Jean。事件函数的滞回阈值 `min(g₀, 0) − ε` 对接触已在“远离时不加滞回”，限位没有；每次反弹后滑块多陷入 ε（10⁻⁹），能量被一点点泵入（Zeno 抽运）。两个引擎同样改为限位远离时不加滞回（`events.ts` / `events.rs`）。修正后该模板 20 个事件，滑块停在限位上。夹具用 `--write-fixtures` 重写（43 个），`cargo test`、全量逐位对照与全部测试重新通过。

日志保存为 `.cache\release-26.52-attempt1.log`。

### 发现并在发布前修正的问题

1. **公式卡片在桌面版中排版错乱（CSP）**：`index.html` 中开场动画的内联 `<style>` 让 Tauri 在构建时把它的哈希加进 CSP 的 `style-src`。按 CSP 规则，`style-src` 中出现哈希或 nonce 后 `'unsafe-inline'` 失效，KaTeX 依赖的内联 `style` 属性（位置、颜色）全部被拦截。浏览器与无头 Chromium 检查不经过 Tauri，所以没有发现。修正：开场样式移到 `src/app/opening.css` 由 `<link>` 引入；`tauri.conf.json` 设 `dangerousDisableAssetCspModification: ["style-src"]`（Tauri 不再改动 `style-src`，脚本的哈希与 nonce 照常）；`tests/version.test.ts` 新增 1 项：`index.html` 不得有内联 `<style>` / `<script>`，`style-src` 含 `'unsafe-inline'` 且该设置存在。
2. **译文**：新增界面键“显示提示”（Show hint / Hinweis zeigen）、“题目提示”、“研究对象”（Body / Körper）、“质点模型”（Particle）、“作用力”（Force），不再借用含义不同的旧键。
3. **受力分析图**：表中小于该力 10⁻⁹ 倍的分量显示为 0；合力箭头被同向的力盖住时向旁边平移 9 px。

修正后容器中：类型检查通过，i18n 2460 个键 0 处问题，**57 个文件 671 项测试通过**，无头 Chromium 中检查了受力分析图（沿接触面分解 + 合力）。

### 记录但未在本版修改的现象

1. **槽底静止时的摩擦力**：小球停在 V 形槽底后，受力分析图给出 N1 = N2 = 4.602 N、f1 = f2 = 2.301 N（= μN，两侧摩擦力沿槽面指向槽底，互相“夹紧”）。这满足平衡与库仑定律，但刚体模型中两侧接触是静不定的，教材取对称解 f = 0、N = mg/(2 cos θ) = 2.991 N。容器中复现：小球在两面间快速交替接触后于 2.3485 s 静止，最后选中的模式是一侧“滑动”（vt = 0，摩擦取 μN）、一侧“粘着”。两侧都粘着时方程组秩不足（4 个未知量、3 个自由度），完全主元消去给出的基本解很可能不满足摩擦锥，因此未被选中（待 26.53 确认）。改进（冗余接触取最小范数解，或静止时重新选择模式）涉及两个引擎的模式选择与逐位对照，放到 26.53；已写入发布说明的已知限制。
2. 组合后复合体的原点 x 显示为 2.07×10⁻¹² m（面积质心的舍入残差），不影响计算，26.53 中对组合与切割得到的坐标做与切割相同的取整。
