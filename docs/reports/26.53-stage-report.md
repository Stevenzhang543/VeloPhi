# 26.53 阶段报告

范围与决策见 `docs/DEV_MANUAL_26_53.md`（D65–D74；实施中的修订见手册 §8）。所有工作都由同一个会话直接完成（没有子代理），没有任何 Git 写操作。

## W 前端 Vue，后端 Rust（D65–D69）

- **Rust 会话**（`engine/velophi-core/src/session.rs`、`api.rs`）：界面线程持有一个会话，收下仿真线程发来的增量数据（字节原样），读数、自定义量、能量账本、情形识别与样本、公式卡片、事件详情、帧视图与力箭头、受力分析图、纸带、面积、箭头比例、曲线降采样、编辑器几何、被逐出帧块的重算都在会话中完成。无状态计算在 `calc.rs`，全部操作见 `engine/CALC.md`；WebAssembly 接口 2（`engine/ABI.md`）。
- **运行驱动** `driver.rs`：WebAssembly、原生桌面引擎（新 crate `engine/velophi-native`，`src-tauri` 中的 `engine_*` 命令）与 N-API 测试模块（`engine/velophi-napi`）共用。原生运行每次一个线程，增量经 Tauri 通道以原始字节传给页面；场景用 `sceneText`、检查点用 `checkpointHex` 传递，保证与 WebAssembly 逐位相同。参数扫描同时运行（逻辑核数 − 1）个点。
- **TypeScript 参照**移到 `tests/reference/`，`src/` 中不再有求解器与数值模块（`tests/architecture.test.ts` 与 `scripts/check-dist.mjs` 检查源码与网页构建）。对照：`scripts/parity.mjs`（求解器与记录）、`scripts/calc-parity.mjs`（会话的全部计算，含小内存预算下的逐出与重算）。
- 前端测试在容器中经 N-API 调用原生 Rust（`tests/setup/core.ts`），在 Windows 发布构建中加载新构建的 WebAssembly。

## F 公式查看（D70–D72）

- **公式面板**（`src/app/components/FormulaPanel.vue`、`src/formula/panel.ts`）：搜索（`/`）、按物体 / 类别 / 判定筛选、只看收藏、紧凑与详细两种密度、按情形或按物体分组、键盘操作；筛选后为空时说明原因。误差显示为 0、百分比或 m×10⁻ⁿ。
- **公式时间轴**（`Timeline.vue`）：每个情形一段色条（类别色、判定下沿、收藏星），瞬时情形为竖线；点击跳转并定位，双击放大；没有可比较公式的情形只画轮廓。
- **联动**：悬停卡片点亮公式变量涉及的物体与力（用到 θ 时画角弧），悬停已知量点亮对应元素；在公式页签中点击物体或力箭头筛选公式。数值标签互相避让。

## X 物理与细节

- **D73 静不定接触**：静止状态下冗余接触先取最小摩擦、再取最小其余约束力（分两级，所选解不可行时保留基本解）；运动中与 26.52 相同。投影后已静止的滑动单元重新确定模式。V 形槽底：f = 0，N₁ = N₂ = mg/(2 cos θ)（相对误差约 10⁻¹⁵）。实施经过见手册 §8。
- **D74**：组合、切割、拆分写入的坐标取 10⁻⁹ 的整数倍。
- 变力箭头按当前值绘制；后台线程补发长帧块的已算帧；核心场景错误按界面语言显示。
- 无头浏览器检查后的修正（手册 §8）：卡片高亮范围、标签避让、详细卡片溢出、隐藏的监视页读取已释放会话的错误（26.52 已有）、时间轴工具栏截断。
