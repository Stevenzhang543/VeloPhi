### 发现并在发布前修正的问题

1. 右侧标签（公式对照 / 属性 / 监视 / 预测 / 场景）切换语言后仍是启动时的语言：标签在根组件中只计算了一次。改为计算属性。
2. 英文中“复制”一律译成 “Duplicate”：指纹旁的“复制”按钮和右键菜单的“复制（Ctrl+C）”显示为 Duplicate。拆成两个键：“复制”→ Copy / Kopieren，“复制一份”（属性页按钮）→ Duplicate / Duplizieren。同时检查了所有在多个文件中出现的短文字，另改“说明”→ Description / Beschreibung、“详情”→ Details。
3. 不限时长运行中切换语言后，情形标题与条件仍是旧语言（增量识别器缓存了已识别的阶段）。语言切换时重建识别器并重新识别已算出的记录。容器中以“英文启动后切到德文”与“直接以德文启动”对比全部标签页、监视页与设置页，除场景数据（物体名称）和计算速度外完全相同。
4. 德文长词：“场景”页运行信息的 “Rechengeschwindigkeit” 与数值重叠；公式卡片标题行在窄面板中把“Details”按钮挤出卡片；时间线在约 750 px 宽时状态标签与按钮被截断。改为标签可断行（`hyphens: auto`）、卡片标题行可换行、时间线状态标签可缩短（省略号）并在 820 px 以下隐藏次要按钮。
5. 德文译文中少数数字用了小数逗号（9,80665、1,62、0,1×），与界面其他数字（小数点）不一致，统一为小数点。
