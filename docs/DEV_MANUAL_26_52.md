# VeloPhi 26.52 开发手册

26.52 是改名后的第一版：项目由 Verity 改名为 **VeloPhi**（艺术字 **VeloΦ**，Φ 是视觉符号）。本版做四件事：**新身份**——全面改名（兼容旧文件）、Φ 图标、从中心快速扩散的开场动画、启动不再闪白；**更整洁的界面**——按任务重新分组、每组可折叠并记住状态，显示效果与动画打磨，手感与反馈在线；**物理补全**——滑轨限位、马达力矩上限、滚动阻力、有心力、辛积分、凹形与复合体、切割；**教学模块**——受力分析图、打点计时器纸带、v–t 图面积、题目模式与题目包。原则、阈值与决策 D1–D52 继续有效（“Verity”字样在旧决策中即指本项目）。

**范围（2026-10-26，维护者确认）：** 维护者在 26.51 发布后提出 7 项要求（V1–V7，见第 2 节）并确认：改名采用“全面改名，兼容旧文件”；界面按“分区折叠 + 记忆”重组；物理与教学做“教学表示”“题目模式”“物理补全”“凹形与复合体”四项。继续顺延到 26.53：链节绳、原生桌面引擎、自定义公式卡、触屏与交互白板（D42）、无障碍（D43）、分享、插件接口、冻结 TypeScript 引擎的评估。

## 4. 本版新增决策

**D53 名称与身份。** 产品名 VeloPhi，读作 “VEE-lo-fai”。ASCII 场合一律 VeloPhi / velophi：程序 `velophi.exe`、Tauri 标识 `app.velophi.physics`、npm 包 `velophi`、Rust crate `velophi-core` / `velophi-wasm` / `velophi-cli`、WebAssembly `src/engine/velophi_core.wasm`、场景格式标识 `velophi-scene`、场景文件 `*.velophi.json`、题目包 `*.velophi-problem.json`、发布文件 `VeloPhi-v26.52-*`、本机存储键 `velophi.*`。展示场合用 VeloΦ（Φ 着强调色）：窗口标题“VeloΦ 26.52”、界面左上角字标、开场动画、关于页、图标、报告与课件的页脚可写 VeloΦ。兼容：读取 `format: "verity-scene"` 的文件（两个引擎都接受），保存时写新标识；本机设置 `verity.settings.v2`、试用日志 `verity.trialLog.v1` 首次启动时迁移到新键（旧键保留不删）；桌面版 WebView2 数据目录从 `%LOCALAPPDATA%\app.verity.physics` 复制到新目录（只在新目录不存在时复制一次，失败不影响启动）。旧发布与 Git 历史不动（工作区由维护者在开发中改名为 `E:\VeloPhi`，构建与发布脚本只用相对路径）；26.51 及以前的文档保留原名作为历史。

**D54 启动与开场动画。** 桌面窗口 `visible: false`、`backgroundColor` 与开场底色相同（#0d0f14）；Rust 在页面加载完成时最大化并显示窗口（另设 4 s 兜底，页面卡住也会出现）。`index.html` 里的开场层（纯 CSS，样式放在 `src/app/opening.css`，用 `<link>` 引入，不依赖脚本与字体文件；不能写成内联 `<style>`，原因见 §7）：深色底、居中的 Φ 标志。界面挂载并画出第一帧后，开场层执行“中心扩散”：界面以 `clip-path: circle()` 从屏幕中心 0 扩到覆盖全屏（420 ms，`cubic-bezier(.2,.8,.2,1)`），Φ 同时放大淡出；完成后移除开场层。系统开启“减少动态效果”（或设置中关闭动画）时改为 150 ms 淡入。网页版相同（无窗口隐藏一步）。

**D55 Φ 图标。** 保持 26.51 图标的构成（深色渐变圆角方形、白色轨迹细线、频闪小球、最后一颗高亮）；轨迹改为 Φ：圆环上等时间间隔的频闪点（匀速圆周运动：点距相等），竖线上自由下落的频闪点（点距按 1:3:5:7 递增），竖线穿过圆心并略伸出圆外。16 px 时只保留圆与竖线。源文件 `assets/icon.svg`、`icon-small.svg`，生成全部尺寸；界面字标 `AppLogo.vue` 同源。

**D56 分区折叠。** 新组件 `Section`（标题、计数、可选操作按钮、折叠箭头），折叠状态按 `面板/分组` 键保存在设置 `ui.sections` 中，跨启动保留；展开/折叠有高度动画（减少动态效果时瞬时）。分组：**顶栏**——左：标志与文件菜单（新建、打开、保存、另存为、最近）；中：页面切换、撤销/重做、模板、题目、教学工具（受力分析、纸带、v–t 面积）；右：计算按钮、显示、扫描、输出、主题。**左侧工具**——常用（选择、平移、小球、物块、地面、斜面、轻绳、弹簧）、物体与形状（圆柱、楔块、多边形、凹形/复合、切割）、环境与场（墙、传送带、定滑轮、有心力）、连接件（轻杆、阻尼器、铰链、焊接、滑轨、马达、齿轮、恒力）、测量与标注；吸附开关收进底部一行。工具栏可收成 56 px 的图标栏（悬停显示名称）。**右侧属性**——基本、位置与运动、质量与转动、材料、阻力、高级（接触对、颜色等），高级默认折叠。**场景页**——场景、物理参数、求解与记录、本次计算，后两项默认折叠。**监视页**——监视量、自定义量、能量账本。**设置页**——左侧目录分为“常用 / 教学 / 系统”三组。

**D57 动效与反馈。** 动效令牌：`--dur-1` 90 ms（按压）、`--dur-2` 160 ms（悬停、切换）、`--dur-3` 240 ms（展开、对话框）、`--ease-out` cubic-bezier(.2,.8,.2,1)、`--ease-spring` cubic-bezier(.3,1.3,.5,1)；只动 transform、opacity、clip-path（高度动画用 grid-template-rows 0fr → 1fr）。反馈：按钮按下缩到 0.97；页签与分段控件的选中块滑动；对话框与菜单缩放淡入；提示从底部滑入；数值框拖动时光标与数值同步、到边界轻微回弹；画布：悬停高亮描边（虚线）、选中实线描边加柔和光晕（**实现决定：**不做流动虚线，它要求画布每帧重绘，静止时也耗电）、吸附时参考线与接触点闪一下（120 ms）、拖动越界时沿接触面滑动（被拖物体与实体的穿入深度超过脱开距离时，投影回表面并沿表面移动）；时间线拖动时滑块放大、显示时间气泡；数值框连续调节碰到上下限时向边界轻推一下。全部遵循“减少动态效果”。

**D58 滑轨限位与马达力矩上限。** 滑轨可设下限 s_min 与上限 s_max（沿轴的相对位移，空表示不限）与限位处的恢复系数 e：两者都是单边约束，与绳的“绷紧/松弛”同样处理——限位闭合时是一行等式（约束力只能向内），约束力变号时打开，到达限位时作为事件定位，带速度时按 e 计算冲量（不增能）。马达（恒转速）可设力矩上限 τ_max：所需力矩 |τ| ≤ τ_max 时锁定转速；超过时进入“打滑”，以 ±τ_max 驱动，相对角速度回到目标值时重新锁定；两种转换都作为事件定位，与静/动摩擦的处理相同。

**D59 滚动阻力。** 圆形物体与面的接触可设滚动阻力系数 C_rr（无量纲，接触对材料中的一项，默认 0）：滚动时在接触处施加阻力偶 M = −sign(ω_rel)·C_rr·N·r；相对滚动角速度为 0 时进入“滚动静止”（相对转动锁定，所需力偶 |M| ≤ C_rr·N·r），超过时开始滚动。接触对的值取两物体中较大者（接触对覆盖时用覆盖值）；r 取圆形一侧的半径（两侧都是圆时取较小者），两物体都不能转动时不起作用。**实现决定：**耗散计入该接触对的“摩擦生热”（总账与分接触对两处），不新增账本项——账本的状态布局影响指纹，新增项会改变 26.51 场景的指纹。模式中每个接触单元多一个可选状态（滚动静止、向正或负方向滚动），事件 rollStart / rollStop 定位转换。

**D60 有心力。** 新的场元素（连接件类型 `central`）：中心点（世界坐标，或某个物体上的点）、作用对象（全部动态物体或指定物体，不含中心所在的物体）、力的大小按幂律 F = k·rⁿ（k > 0 为引力、指向中心，k < 0 为斥力；n 在 −4…4 之间），沿中心连线作用于质心；中心在动态物体上时反作用力作用在该点。在目标物体的外接半径 R 以内力按 k·Rⁿ·r/R 线性减小到 0（与 26.51 万有引力的软化相同，r → 0 时不发散）。**实现决定：**不用任意表达式而用幂律，势能有解析式 k·rⁿ⁺¹/(n + 1)（n = −1 时 k·ln r；R 以内为二次式，在 R 处连续），计入机械能（新的“场势能”分量），不计入“外力做功”，账本平衡不变。常用预设：弹性中心力 n = 1、平方反比 n = −2。斥力随距离增大（k < 0、n ≥ 1）可能在有限时间内把物体推到无穷远：状态出现非有限值时自适应积分先缩小步长，定步长方法与 Moreau–Jean 直接以 `err.stateNotFinite` 停止。

**D61 Gauss–Legendre 辛积分。** 积分方法新增 `gauss4`：2 级 4 阶隐式 RK，定步长 Δt；级方程用不动点迭代，收敛判据（各分量变化 ≤ 4ε·max(1, |值|)）与 50 次上限在两个引擎中相同，从而逐位一致。事件仍精确定位。适用于无耗散的长时间运动；有摩擦、阻尼时可用但不再保持能量。

**D35 修订：凹形与复合体、切割。** 形状新增 `polygon` 的凹多边形（简单多边形，逆时针，自交时拒绝）与 `compound`（若干圆、矩形、多边形，各带局部位置与角度）。质量属性：多边形用鞋带公式直接计算面积、质心、转动惯量；复合体按各部分面积（均匀密度）合成并用平行轴定理，部分重叠时按重叠部分重复计入；动态复合体的各部分按整体质心重新定位（警告 `warn.compoundCentred`）。碰撞：凸多边形仍走 26.51 的代码（场景结果逐位不变）；凹多边形与复合体编译为“复杂形状”：每个多边形部分按确定性的耳切 + 合并相邻块（Hertel–Mehlhorn）分解为凸块，圆部分本身是一个块。接触特征取自各部分的外边界——每条边一个面特征，凸顶点与圆心各一个点特征，凹顶点不作为点特征（它不可能最先接触）；每个特征记下所在的凸块。探针（新接触的事件函数）改为“对方每个点 × 本体每个凸块”的有向距离：一个点已经贴着某个凸块时，它对其他凸块的探针仍在工作（小球滚进 V 形槽时会碰到第二个面）。一对物体可以在法向不同的几处同时接触：凡涉及复杂形状的物体对，按接触法向（统一定为由 Y 指向 X）是否平行同向把接触点分成多个接触单元，各有自己的切向与摩擦状态。同一复合体内部不检测碰撞。切割工具：沿画出的直线把多边形、矩形或凹多边形分成多块（凹多边形可能切成两块以上；质量按面积分配，速度为切割处的刚体速度），一次切割可撤销。

**D35 补充（凹形与复合体的编辑与识别）。** 物体吸附：复合体的每个部分各自参与吸附（键名带部分序号），凹多边形的内外判断改用射线法；复合体部分的顶点与圆心也是特征点。情形识别：物体在面上（斜面、平面、滚动）的阶段签名加上接触面的法向角，凹形物体的不同面不会合并成一个阶段；有滚动阻力的接触不识别为“纯滚动”（其公式不含阻力偶）。新增模板“弹性中心力”“滑轨限位”“滚动阻力”“V 形槽中的小球”（共 35 个），两个引擎逐位一致。

**D62 受力分析图。** 对选中物体在当前时刻画隔离体图：物体按简化形状（或质点小圆）画在白底上，力按教材顺序（重力、弹力/支持力、摩擦力、拉力、弹簧力、阻力、引力、其他）列出，每个力标符号（G、N、f、T、F弹 …）；画法可选“实际作用点”或“共点力（画在重心）”；可选显示大小、沿斜面或坐标轴分解（虚线分量）、合力；数据来自求解器在该时刻的约束力（与画布上的力箭头同源）。可导出 PNG 与 SVG，可插入报告与课件。**实现决定：**纯模块 `src/teaching/fbd.ts`（`fbdData` 取该时刻的精确状态与模式解，`fbdSvg` 生成独立 SVG）；画布的 `bodyForces` 给每个力加上类别（gravity、normal、limit、friction、tension、pin、spring、damper、drag、attract、central、applied），图按类别排序。同一接触单元的几个接触点合成一个支持力，作用点取压力中心（按各点力的大小加权）；同一符号出现多次时编号（N1、N2）。求解器中没有单独列出的约束力（齿轮啮合、绕过动滑轮的绳等）之和 m·a − ΣF 画成“F其他”，保证图中各力之和等于 m·a，对话框同时显示 |ΣF| 与 m·|a| 的核对。分解“沿接触面”取最大支持力的切向；没有接触时退回坐标轴。箭头长度与力成正比，最大力 120 px，非零力至少 18 px；标签在箭头端点周围按与轮廓、坐标轴、箭头、其他标签的重叠最少放置，带底色描边保证可读。插入：实验报告新增“受力分析图（所选物体，当前时刻）”一项（SVG 内嵌）；课件包本版不自动加入，可把导出的 PNG 手动放入。

**D63 打点计时器纸带。** 选择物体与方向（运动轨迹的路程，或某一坐标轴），打点周期 0.02 s（可改），计数点间隔 5 个点（T = 0.1 s，可改），起点可选；从记录的精确状态生成点位（不是从帧插值），画成纸带，列出各段长度 x₁…x₆、各计数点瞬时速度 vₙ = (xₙ+xₙ₊₁)/(2T)、逐差法加速度，并与仿真加速度（该段时间平均）对照。可导出 PNG 与 CSV。**实现决定：**`src/teaching/tape.ts`。路程方向的点位为 |v| 在相邻两点间 4 段 Simpson 积分（匀变速直线运动时精确）；沿坐标轴为坐标差。计数段数默认 6、最多 12，记录不够时自动减少；逐差法用前 2m 段：a = [(x_{m+1}+…+x_{2m}) − (x₁+…+x_m)]/(m²T²)。仿真平均加速度 = 所用时间段首末速度之差 ÷ 时间。纸带按原大（96 dpi）绘制，放不下时等比缩小并注明比例。打点周期与计数间隔保存在设置 `teaching.tape` 中。

**D64 v–t 图面积。** 在速度曲线上按住 Shift 拖选时间段：曲线与时间轴之间的面积着色（正负不同色），标注面积值 = 该段位移（数值积分，复合 Simpson，用记录帧），并与位移的直接读数对照。**实现决定：**`src/teaching/area.ts`。区间端点取最近的帧；偶数个间隔用复合 Simpson，奇数个时最后三段用 Simpson 3/8 规则，只有一段时用梯形。正、负部分分别积分（两者之和即面积）。对照量：vₓ → x、v_y → y、aₓ → vₓ、a_y → v_y、ω → θ、β → ω；其他量（力、功率…）只给面积与单位（N·s、J…）。同一张图上的每条曲线各给一个面积；一次最多 200 000 帧。“教学 › v–t 图面积”把所选物体的 vₓ、v_y 放进曲线面板并提示操作。

**D40 修订：题目模式与题目包。** 题目 = 场景 + 题干 + 若干问题。问题类型：数值题（答案来自仿真：某个观测量在某时刻、某事件处或运行结束时的值，单位、相对容差，默认 2%）与选择题；可带提示与解析。答案由仿真得出而不是手写，所以改场景参数后答案自动更新；可选“理论答案”（由公式库对应卡片给出，对照显示）。作答流程：打开题目时画布停在 t = 0、曲线与公式卡片隐藏；学生填写后“揭晓”：运行动画、逐题判对错并给出正确答案、解析与相关公式卡片。教师：从当前场景“新建题目”，用观测量选择器添加问题；导出题目包 `*.velophi-problem.json`（场景格式 4 + 题目，明文答案，教学用途不做防作弊），可导入。内置 30 道题，按教材章节组织（匀变速直线运动、相互作用、牛顿运动定律、抛体、圆周运动、万有引力、机械能、动量、振动、转动），由模板加参数生成。**实现决定：**`src/teaching/problems.ts`（数据结构、判分、文件格式）、`problemBank.ts`（30 道题）、`src/app/problemMode.ts`、`ProblemPanel.vue`（右侧“题目”页签，只在题目模式中出现）、`ProblemGallery.vue`。答案来源沿用“预测与对比”的三种目标（事件时刻、某时刻的量、公式结果），另加三种：事件前/后瞬间的量（取事件前后的精确状态）、运行结束时的量、全程最大/最小值。公式结果类的题目同时给出公式卡片的理论值；公式对该情形不适用时不显示理论值。选择题的正确选项可固定，也可由仿真决定（某个值超过几个界限就是第几个选项），换参数后仍然正确。判分：|答案 − 仿真值| ≤ 容差·|仿真值| + 绝对容差（默认 2% 与 10⁻⁶）。内置题的题干用 `{参数名}` 引用模板参数，文字三语内置；“换一组数据”在每道题给定的范围内按步长随机取参数，题目场景设为有限时长。作答期间（`problemLocked()`）：播放、拖动时间线与跳转被拦截，曲线、事件、公式对照、监视读数与渲染页显示“作答期间暂时隐藏”，画布不画受力、加速度、轨迹、关键时刻与频闪，教学菜单不可用。题目包格式 `{ format: "velophi-problem", version: 1, problem }`，场景以场景文件格式内嵌；用“打开…”打开题目包也会进入题目模式。

**实机检查中的修正（CSP）。** 第一次 Windows 构建中公式卡片排版错乱、颜色丢失。原因：`index.html` 的内联 `<style>` 让 Tauri 在 CSP 的 `style-src` 中加入该块的哈希；按 CSP 规则，出现哈希或 nonce 后 `'unsafe-inline'` 失效，KaTeX 依赖的内联 `style` 属性全部被拦截（浏览器与无头检查不经过 Tauri，所以看不出来）。修正：开场样式移到 `src/app/opening.css`；`tauri.conf.json` 设 `dangerousDisableAssetCspModification: ["style-src"]`，Tauri 不再改动 `style-src`（脚本的哈希与 nonce 照常）；`tests/version.test.ts` 检查 `index.html` 没有内联 `<style>`/`<script>`、`style-src` 含 `'unsafe-inline'` 且该设置存在。
