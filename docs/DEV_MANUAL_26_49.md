# Verity 26.49 开发手册

26.49 在 26.48 的基础上做三件事：用真实师生试用的结果打磨产品；把覆盖面从 8 个验收场景扩展到高中和大学一年级力学的常见模型；补齐老师要的课件交付链路。26.48 的原则、架构和阈值（`DEV_MANUAL_26_48.md` 第 2、3、6 节）全部沿用；本版新增或修改的决策在第 3 节追加。

## 1. 版本目标

| 优先级 | 功能 | 要求 |
| --- | --- | --- |
| P0 | 试用与修正 | 至少 3 位物理老师、5 位物理专业学生按任务单试用 26.48；问题全部登记，严重问题在本版修复，其余写明处理计划 |
| P0 | 26.48 遗留 | 26.48 发布说明“已知限制”中标为 26.49 的条目全部完成或给出不做的理由 |
| P0 | 新模型 | 竖直面圆周运动（绳与杆，最高点临界速度）、动滑轮与滑轮组、可动斜面（斜面在光滑地面上）、弹簧连接体（含碰撞后压缩最大时刻）、滚动带滑动（保龄球模型）、变力 F(t)（表达式输入） |
| P0 | 计算与界面分离 | 求解放到 Web Worker，界面在长时间计算时不卡顿；记录可按需降采样存储 |
| P1 | 课件导出 | 一键导出“课件包”：MP4 视频、关键时刻截图（PNG，透明或白底）、公式卡片（SVG/PNG）、CSV；可选直接生成 PPTX（每个关键时刻一页：截图 + 公式 + 读数） |
| P1 | 预测与对比 | 学生在运行前填写自己的计算结果（如共速时刻），运行后自动与仿真和公式对比 |
| P1 | 参数扫描 | 选一个参数和范围批量运行，输出“结果–参数”曲线与 CSV（如共速时刻随 μ₁ 变化） |
| P1 | 测量工具与标注 | 尺子、量角器；手动标注文字和箭头，随场景保存；投影仪模式（大字号、高对比度） |
| P1 | 实验报告 | 导出 HTML/PDF 报告：场景截图、参数表、曲线、公式对照与误差 |
| P2 | 大场景后备 | 接触很多或碰撞累积时，切换到 Moreau–Jean 时间步进（明确标注精度降级），不影响默认的事件驱动求解 |

## 2. 不做

电磁、光学、波动、热学；AI 生成场景；多人协作与班级管理；流体与软体；通用游戏功能；3D 渲染。架构上继续保留接口：求解器按“维度模块”组织，公式层按“领域”组织。

## 3. 本版新增决策

**D13 计算放入 Web Worker。** 26.48 在主线程分片计算，复杂场景下界面会掉帧。26.49 把求解器和记录放进 Worker，界面通过只读的共享内存（SharedArrayBuffer，网页包需要 COOP/COEP 响应头；不满足时退回消息传递）读取快照。核心代码不变，仍可在 Node 中测试。

**D14 变力表达式。** 外力可写成时间与状态的表达式（如 `10*sin(2*pi*t)`），复用公式层的表达式解析器和量纲检查；表达式在求解器的右端项中求值，只读状态，不得含随机数。表达式不连续处（如分段函数的断点）作为事件处理，以保证精度。

**D15 课件导出格式。** PPTX 用开源库生成（选型时先确认许可证为 MIT/Apache 一类），视频作为嵌入媒体；不支持 PPTX 的场合用“课件包”文件夹。截图与公式卡片用同一渲染器离线生成，与界面一致。

**D16 试用数据。** 试用版可选开启本地操作日志（不含个人信息，不上传），由试用者手动导出给我们；默认关闭。

## 4. 新模型的验收

| 模型 | 设置 | 自动核对 |
| --- | --- | --- |
| 竖直面圆周（绳） | L = 0.5 m，最低点 v₀ 可调 | 最高点临界速度 √(gL)；v₀ < √(5gL) 时绳在何处松弛（事件时刻与位置） |
| 竖直面圆周（杆） | 同上 | 最高点杆力方向随速度改变，临界 v = √(gL) 时杆力为 0 |
| 动滑轮与滑轮组 | 一个动滑轮、两个定滑轮 | 加速度关系 a₁ = 2a₂，张力关系，整体能量守恒 |
| 可动斜面 | 斜面 M 在光滑地面上，滑块 m 无摩擦下滑 | 水平动量守恒，斜面加速度解析式 |
| 弹簧连接体 | 两滑块经弹簧相连，一个获得初速度 | 最大压缩时刻两者共速，动量守恒，弹性势能最大值 |
| 滚动带滑动 | 圆柱以 v₀、ω₀ = 0 放在粗糙地面 | 打滑时间 t = 2v₀/(7μg)（实心球）或对应圆柱公式，此后纯滚动 |
| 变力 | F = F₀ sin(ωt) 作用于光滑面上的滑块 | 速度、位移与积分解析式一致 |

阈值沿用 26.48 第 6 节。

## 5. 试用流程（阶段 5 门槛）

1. 准备任务单：老师 4 项（搭板块模型并在共速时暂停讲解、导出视频插入 PPT、改参数比较、找出一条“近似失效”提示并解释）；学生 4 项（搭传送带、导出 v-t 数据画图、与手算对比、用参数扫描验证一个结论）。
2. 每次试用记录：完成时间、卡住的地方、误解的提示、提出的需求。
3. 问题分级：阻断（无法完成任务）、严重（结果被误解或需要求助）、一般、建议。阻断和严重必须在 26.49 修复。
4. 汇总报告放在 `docs/reports/trial-26.49.md`，发布说明列出处理结果。

## 6. 测试与发布

- 26.48 的全部测试继续通过；新增模型各有解析基准与公式正反例。
- Worker 版本与主线程版本的记录哈希一致。
- 课件导出：生成的 PPTX 能被 PowerPoint 与 WPS 打开（在 Windows 上手动验证并截图存证）。
- 发布产物与流程同 26.48；版本号 26.49.0；不做任何 Git 写操作。
