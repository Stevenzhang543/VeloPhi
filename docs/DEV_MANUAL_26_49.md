# Verity 26.49 开发手册

26.49 在 26.48 的基础上做三件事：用真实师生试用的结果打磨产品；把覆盖面从 8 个验收场景扩展到高中和大学一年级力学的常见模型；补齐老师要的课件交付链路。26.48 的原则、架构和阈值（`DEV_MANUAL_26_48.md` 第 2、3、6 节）全部沿用；本版新增或修改的决策在第 3 节追加。

## 2. 不做

电磁、光学、波动、热学；AI 生成场景；多人协作与班级管理；流体与软体；通用游戏功能；3D 渲染。架构上继续保留接口：求解器按“维度模块”组织，公式层按“领域”组织。

## 3. 本版新增决策

**D13 计算放入 Web Worker。** 26.48 在主线程分片计算，复杂场景下界面会掉帧。26.49 把求解器和记录放进 Worker，界面通过只读的共享内存（SharedArrayBuffer，网页包需要 COOP/COEP 响应头；不满足时退回消息传递）读取快照。核心代码不变，仍可在 Node 中测试。

**D14 变力表达式。** 外力可写成时间与状态的表达式（如 `10*sin(2*pi*t)`），复用公式层的表达式解析器和量纲检查；表达式在求解器的右端项中求值，只读状态，不得含随机数。表达式不连续处（如分段函数的断点）作为事件处理，以保证精度。

**D15 课件导出格式。** PPTX 用开源库生成（选型时先确认许可证为 MIT/Apache 一类），视频作为嵌入媒体；不支持 PPTX 的场合用“课件包”文件夹。截图与公式卡片用同一渲染器离线生成，与界面一致。

**D16 试用数据。** 试用版可选开启本地操作日志（不含个人信息，不上传），由试用者手动导出给我们；默认关闭。

以下 D17–D25 是开发中做出的决策，按 26.48 手册第 3 节的约定追加。

**D17 碰撞中的摩擦：单点碰撞用 Stronge 能量恢复系数。** 26.48 的碰撞冲量是光滑的（D4）。牛顿（运动学）恢复系数与库仑摩擦合用时，某些偏心碰撞会凭空增加动能；Stronge 的能量恢复系数（释放压缩功的 e²）保证动能不增加。实现（`core/solver/impact.ts`）：先按 26.48 的方法求光滑冲量；若只有一个单侧约束起作用且该接触对 μ > 0，就以法向冲量为参数沿冲量路径重算：铰链和杆的冲量先用 Schur 补消去，接触点只看到一个 2×2 的等效逆质量；每一段路径上速度随法向冲量线性变化：滑动时 dPt = ∓μk·dPn，切向相对速度过零后，若保持黏着所需的摩擦增量不超过 μs（|Wnt| ≤ μs·Wtt）就黏着，否则反向滑动；压缩在法向速度为零处结束，恢复阶段再释放 e² 倍的压缩功——每一段都是闭式解。若结果会把其他接触推向互相穿入、路径无法走完，或动能会增加（传送带做功除外），就退回光滑冲量。多个接触点同时发生摩擦碰撞时没有同样可靠的模型，保留光滑冲量（仍是耗散的）并记录警告。μ = 0 时直接返回光滑解，与 26.48 逐位相同。公式层中假设光滑接触的碰撞公式增加条件“碰撞冲量无摩擦”。绳突然绷紧仍按 e = 0 处理。

**D18 Moreau–Jean 时间步进作为后备，并明确标注精度降级（手册第 1 节 P2）。** 接触很多（堆叠、颗粒）或碰撞无限累积时，事件驱动的求解在一个时刻附近原地打转。此时与其停止，不如用时间步进算完，并把精度降级写在所有能看到结果的地方。触发：用户在“场景”页选 `moreau`，或事件堆积（0.05 s 仿真时间内超过 400 个事件，或同一时刻超过 200 次状态切换；`SimOptions.fallback: false` 保留 26.48 的“停止并报错”）。算法（`core/solver/moreau.ts`）：每个输出间隔 4 步；外力显式；所有约束的冲量用投影 Gauss–Seidel 固定 60 遍求解（铰链、杆、接触含预测接触、摩擦锥、绷紧的绳）；之后用质量加权投影去掉穿入和铰链漂移。循环顺序和遍数固定，结果仍可逐位复现。标注：`Recording.reducedFrom`、`Segment.reduced`、事件“改用时间步进（精度降级）”、一条说明性警告；公式识别只用切换之前的部分；两帧之间改为线性插值（没有连续解）；冲量去掉的能量合计记为“碰撞损失”。

**D19 含变力的场景把时间放进状态。** 变力表达式可以含 t。把 t 作为状态向量的一个分量（dt/dt = 1）后，右端项只依赖状态，积分器、事件定位、帧间精确状态（`exactStateAt`）和线程间传输都不用改。每个记录帧把这一分量置为网格时刻 k·Δt，不累积舍入。只有含表达式的场景才有这一分量，其他场景的状态长度和结果指纹与 26.48 相同。表达式中的分段函数（step、sign、if、abs、min、max、clamp）是“开关”：每个开关的分支在一个阶段内冻结、属于接触模式的一部分，切换参数是事件函数，所以右端项在阶段内光滑，跳变和折点被精确定位（D14 的落实）。1 µs 内同一开关切换超过 40 次即停止并给出原因（如 `sign(vx)` 在 vx = 0 处）。变力的功计入能量账本。

**D20 线程间传输与渐进记录（修订 D13）。** 不用 SharedArrayBuffer：它要求网页包带 COOP/COEP 响应头，学校的服务器常常配不了。改为消息传递：Worker 每约 100 ms（墙钟）发送一次“增量”（新算出的帧、阶段、事件，类型化数组以 transfer 方式传递，不复制）；界面线程用同一份场景重新编译系统，把模式里的接触对、接触特征按索引还原成自己的对象，所以帧、模式解和指纹都与在本线程计算逐位相同（`core/solver/transport.ts`）。`SimulationRun.advance(deadline)` 无论怎样分片都执行同一算法；`partial()` 给出最终记录的一个一致前缀，界面可以边算边播，公式识别在计算完成后进行。无法创建 Worker，或 Worker 脚本在发出第一条消息前加载失败（file://、CSP 限制）时，改为在界面线程中每片约 12 ms 分片计算。取消：发消息并终止 Worker，界面保留最后收到的部分记录。

**D21 单一单位表，只在显示边界换算。** 场景文件、求解器、记录、公式层和设置中的物理量一律国际单位；只在输入提交和显示时换算（`src/units/units.ts`，按 SI 单位字符串查表，pure 模块，导出器和测试直接使用）。十进制前缀用整数倒数换算（30 cm → 最接近 0.3 m 的双精度数）。CSV 在“国际单位”模式下写双精度原值，在“显示单位”模式下只做一次乘除。测试保证每个观测量、公式、识别变量和变力变量的单位都在表中，新增量忘记登记单位会失败。重力只有一个默认值，用于新建场景和模板；场景一旦创建就保留自己的 g，公式一律取场景的 g。显示单位属于应用设置，不写入场景文件。

**D22 连续时间播放；插值只用于绘制。** 慢放和运动模糊需要两帧之间的画面。两帧之间没有事件时用三次 Hermite 插值（记录的位置与速度，误差 O(Δt⁴)，远小于一个像素）；区间内有事件时从上一帧按正确的模式精确积分。读数、曲线、CSV、公式对照只取记录帧或 `exactStateAt` 的精确状态；视频和截图导出也用精确状态（`exact: true`）。这样画面可以平滑，而“画面上的数字来自求解器”（26.48 原则 1）不变。

**D23 视觉效果无状态、可复现。** 运动模糊、粒子、拖尾只从记录派生，从不写回任何读数。粒子的发射器在每个记录上由事件和阶段一次性生成，每个粒子在时刻 t 的位置是“t − 发射时刻”与“发射器种子、粒子序号的哈希”的闭式函数，不用随机数、不积分。因此倒退拖动、慢放和导出视频看到的粒子完全一致，导出的画面可复现（26.48 原则 2 也适用于画面）。每帧最多 400 个粒子；运动模糊每帧 6–12 个子帧样本。效果有“关闭 / 标准 / 高”三档，配置低的电脑和投影时可关闭。

**D24 场景格式 2。** 新增可选字段：`annotations`（文字、箭头、尺子、量角器，世界坐标）、`PulleyDef.body`（动滑轮所在物体，轮轴坐标相对该物体）、`ForceDef.expr`（变力表达式，读取时检查）。格式 1 → 2 的迁移只补空的标注列表；其余字段缺省即旧含义。预测（`extra.predictions`）放在已有的扩展字段中，不需要再升格式。标注不影响仿真：修改标注是可撤销的一步，但不会让已有记录失效。键顺序、数值写法和未知字段保留规则同 26.48（D11）。

**D25 试用日志的隐私规则（落实 D16）。** 默认关闭，关闭时不记录任何内容。只存在本机（localStorage 环形缓冲，最多 5000 条），从不上传，由参与者在设置页手动导出 JSON 或清除。记录内容只有事件类型和标识符：键和值必须匹配短 ASCII 标识符的格式，名称、路径、文件、文字、备注一类的键一律丢弃，含空格、斜杠或非 ASCII 字符的值也丢弃。每次启动开始一个随机的匿名会话号，不对应任何人。

## 4. 新模型的验收

| 模型 | 设置 | 自动核对 |
| --- | --- | --- |
| 竖直面圆周（绳） | L = 0.5 m，最低点 v₀ 可调 | 最高点临界速度 √(gL)；v₀ < √(5gL) 时绳在何处松弛（事件时刻与位置） |
| 竖直面圆周（杆） | 同上 | 最高点杆力方向随速度改变，临界 v = √(gL) 时杆力为 0 |
| 动滑轮与滑轮组 | 一个动滑轮、两个定滑轮 | 加速度关系 a₁ = 2a₂，张力关系，整体能量守恒 |
| 可动斜面 | 斜面 M 在光滑地面上，滑块 m 无摩擦下滑 | 水平动量守恒，斜面加速度解析式 |
| 弹簧连接体 | 两滑块经弹簧相连，一个获得初速度 | 最大压缩时刻两者共速，动量守恒，弹性势能最大值 |
| 滚动带滑动 | 圆柱以 v₀、ω₀ = 0 放在粗糙地面 | 打滑时间 t = 2v₀/(7μg)（实心球）或对应圆柱公式，此后纯滚动 |
| 变力 | F = F₀ sin(ωt) 作用于光滑面上的滑块 | 速度、位移与积分解析式一致 |

阈值沿用 26.48 第 6 节。

## 5. 试用流程（阶段 5 门槛）

1. 准备任务单：老师 4 项（搭板块模型并在共速时暂停讲解、导出视频插入 PPT、改参数比较、找出一条“近似失效”提示并解释）；学生 4 项（搭传送带、导出 v-t 数据画图、与手算对比、用参数扫描验证一个结论）。
2. 每次试用记录：完成时间、卡住的地方、误解的提示、提出的需求。
3. 问题分级：阻断（无法完成任务）、严重（结果被误解或需要求助）、一般、建议。阻断和严重必须在 26.49 修复。
4. 汇总报告放在 `docs/reports/trial-26.49.md`，发布说明列出处理结果。

## 6. 测试与发布

- 26.48 的全部测试继续通过；新增模型各有解析基准与公式正反例。
- Worker 版本与主线程版本的记录哈希一致。
- 课件导出：生成的 PPTX 能被 PowerPoint 与 WPS 打开（在 Windows 上手动验证并截图存证）。
- 发布产物与流程同 26.48；版本号 26.49.0；不做任何 Git 写操作。
