**修订（2026-10-27，26.54 发布后）：** 按 26.54 的实施记录（26.54 手册 §10）修订第 2 节的预案：D89 的“运行”并入现有的直流电路实验（同一个编辑器，新元件 + 时域运行）；D90 的场区进出用核心已有的“开关事件”机制（冻结的分支 + 事件定位），不新增事件类型的求解路径；D91、D92 只对用到它们的场景生效（不用的场景逐位不变，D77 的“Rust 专有场景”判断扩展到这些功能）；机械效率的通用读数（26.54 R8 顺延）写入 D92 之后。**维护者对本版的要求：** 优化性能，但精度与计算结果不能有任何妥协——新增 **D97**：所有性能改动必须逐位不改变计算结果，以全部对照与指纹验证。

## 2. 决策

**D89 电路的时间推进。** 直流电路实验增加“运行”（时域），与稳态分析共用一个编辑器。Rust `labs/transient.rs`：改进节点分析，电容与电感用梯形法伴随模型，步长按误差控制自动调整（一步与两个半步之差，相对容差 10⁻⁹；实施时改为 10⁻¹¹，见 5.2 R1）；开关动作、二极管通断、保险丝熔断与漏电保护跳闸之后的第一步用 10 个后向欧拉小步（避免梯形法在不连续处的振荡；实施时改为一致初值加两个极短的后向欧拉步，见 R1）。新元件：电感、交流电源 u = U_m sin(ωt + φ)、二极管（分段线性：导通压降 + 导通电阻）、直流电动机 / 发电机（U = I·R_a + kω，Jω̇ = kI − bω − τ_负载；“发电机”方式转速由外部给定）、变压器（理想变压器 + 初级励磁电感与绕组电阻：直流时次级电压衰减为零）、保险丝（I²t 熔断）、漏电保护器（火线与零线电流之差超过 30 mA 跳闸）、热敏 / 光敏 / 压敏电阻、灵敏电流计（满偏电流、内阻、指针偏转）、示波器探头 CH1 / CH2。运算无状态：请求带上初始状态（电容电压、电感电流、转速、通断状态），返回采样与末状态，界面按动画时间分段请求，运行中拨动开关从当时的状态继续。稳态分析中电感当作导线、保险丝与传感器当作电阻；交流电源、变压器、电动机只在“运行”中有意义（稳态给出提示）。

**D90 有界场区。** 场景中可加入矩形与圆形的场区，区内有匀强电场（可为交流 E₀cos(ωt + φ)）和 / 或匀强磁场。带电物体的质心是否在区内，作为“开关”的分支冻结在模式中（场景中开关的分支向量之后），段内的力是光滑的；质心到边界的有符号距离是事件函数，进出区域由核心已有的事件定位求得。区域电场不是保守场：它做的功记入账本的“外力做功”，读数中单列“场区电场做功”。

**D91 电磁感应耦合。** 新连接件“导轨回路”：一个物体（导体棒）沿给定方向的导轨运动（导轨用已有的滑轨约束），回路电阻 R、导轨间距 L、磁感应强度 B（垂直纸面）；ε = BLv、I = ε/R、安培力 F = BIL 沿导轨方向阻碍相对运动，相当于线性阻尼 B²L²/R；焦耳热记入账本的耗散项，读数中单列“焦耳热”。识别“导体棒切割磁感线”情形，给出 ε、I、F 与收尾速度 v = FR/(B²L²)（恒力）或 mgR/(B²L²)（竖直导轨）。线圈中磁通变化与楞次定律在“磁场”实验中演示（磁通量读数），运行时的线圈耦合顺延。

**D92 液体区域。** 场景中可加入液体（矩形区域，密度 ρ，液面高度 = 区域上沿）。浸入部分由物体的多边形（圆按解析弓形）与液面、区域侧边裁剪求得（二维中按单位厚度，读数说明“每米厚度”），浮力 ρgA 作用于浸入部分的形心（因此有扶正力矩）；可选液体阻力（线性 + 平方，按浸入比例）。物体最低点、最高点穿过液面是事件（浮力的导数在此不连续）。读数：液体中某点的压强 p = p₀ + ρgh、浸入面积、浮力。

**D92b 机械效率的通用读数。** 系统读数增加“机械效率”：选定“有用”的物体与有用功的方向（克服重力：竖直向上；或沿某一方向），有用功 = 物体沿该方向的势能 / 位移功的增量，总功 = 外力与电机做功；η = W有/W总，从运行开始或从选定时刻算起。

**D93 波的数值模型。** 一维弦离散为 N 个质点，蛙跳法（leapfrog）积分波动方程，时间步 Δt = Δx/c_max（c 均匀时 Courant 数为 1，格点上与连续方程的解完全相同）；端点固定 / 自由 / 驱动 / 吸收（一阶 Mur 边界）；可分两段介质（波速不同）看反射与透射。横波、纵波只是显示方式不同。多普勒效应与声音（音调、响度，可用 WebAudio 播放）在同一实验中。波动光学用夫琅禾费近似的解析强度：双缝、单缝、N 缝光栅、薄膜（两束反射光干涉，含半波损失）、偏振片（马吕斯定律，多片）；白光按 380–780 nm 的光谱求和，屏上颜色按波长换算。

**D94 一维量子实验室。** 约化单位 ħ = m = 1（界面换算为电子在 nm 与 eV 下的值）；分步傅里叶法（split-operator，二阶 Strang 分裂，自写的基 2 复数 FFT）积分含时薛定谔方程；势能：自由、方势垒、方势阱、无限深势阱、谐振子、双势垒；边缘可加吸收层。本征态：有限差分哈密顿量（对称三对角）的最低若干本征值用 Sturm 序列二分到机器精度，本征向量用反幂迭代。显示 |ψ|²、实部 / 虚部、期望值 ⟨x⟩、⟨p⟩ 与不确定度、透射与反射概率。

**D95 气体与循环。** 理想气体 pV = nRT 的准静态过程（等温、等压、等容、绝热 pV^γ = 常量）用闭式解；p–V 图画过程线，读数 W、Q、ΔU，热力学第一定律逐项对照；预设卡诺循环与奥托循环，效率与 1 − T₂/T₁、1 − 1/r^(γ−1) 对照。气缸中的分子只作示意（速率按 √T 缩放，界面注明）。

**D96 学习路径与全局搜索。** 学习路径按课程标准的模块顺序（初中、高中必修 1–3、选择性必修 1–3、大学）列出“模板 → 实验 → 题目 → 手册”，完成情况记在本机设置中。全局搜索（Ctrl+K / ⌘K）同时搜工具、模板、实验、公式与手册条目，结果按类别分组，回车打开。

**D97 性能与精度。** 维护者的要求：性能优化不能以精度为代价。规则：（1）求解器、计算层与参照中的任何改动都必须使全部对照（`parity.mjs`、`calc-parity.mjs`）与 WebView2 自检的指纹逐位不变；浮点运算的顺序不能改（例如 J M⁻¹ Jᵀ 不能按对称性只算一半——`a·b·c` 与 `c·b·a` 舍入不同，试验中 77 个场景的指纹因此改变，已撤回）。（2）界面的优化只改“何时算、算几次”，不改“算什么”：缓存必须以全部输入为键，失效后重算。（3）每项优化都记录前后的测量值（同一台机器、同一场景、同一操作）。

### 5.2 决策修订与实现说明

- **R1（D89，误差控制）。** 默认相对容差改为 **10⁻¹¹**（手册原写 10⁻⁹）：10⁻⁹ 时 LC 振荡在长时间运行后的相位误差超过验收要求的 10⁻⁶，10⁻¹¹ 时满足且仍然流畅。步长取 h = Δt/2^k，采样点恰好落在步点上。不连续处不用“10 个后向欧拉小步”，而是先求“一致初值”（电容当电压源、电感当电流源求解）；无解时用两个长 10⁻⁹ Δt（再不行 10⁻⁷、10⁻⁵）的后向欧拉小步越过跳变，时钟随后复位，只有确实损失了能量才报告“突变”事件。LU 分解先做行列均衡（主元阈值 10⁻¹³），分解按（方法, h）缓存。保险丝用 ∫(I² − I_r²)dt 的熔断积分（加热与冷却，不小于 0），漏电保护器用剩余电流平方的低通（τ = 20 ms）；能量用中点乘积计算（对伴随模型是精确的）。
- **R2（D90，场区的分支）。** 场区与带电物体的“区内 / 区外”状态冻结在模式的开关向量中，排在场景开关之后（`branch_count`、`zone_sw`、`mode_branches`）；事件类型 `zone`，状态变化 `zoneEnter` / `zoneLeave`。账本的附加项（场区电场做功、浮力做功、焦耳热、液体阻力耗散）放在接触对之后、时间之前；不用新功能的场景状态布局不变，指纹不变。分支场景继承这些累计值（`branchState` 与 `startLedger` 的四个新字段）。
- **R3（D91，导轨回路）。** 导轨回路不强加约束：它是沿导轨方向的线性阻尼力 B²L²v/R（v 为导体棒沿导轨的速度分量），导体棒是否只沿导轨运动由受力决定（模板中垂直导轨方向不受力）。画面画出两条导轨、电阻与 B 的标记；读数 ε、I、F、P。
- **R4（D92，液面事件）。** 液面穿过物体最低点 / 最高点**没有**设为事件：浮力本身连续，只有导数在此不连续，自适应步长在此处自动缩小（误差估计拒绝步长），漂浮测试中吃水深度与解析值相差 < 10⁻⁶ m，能量账本闭合 < 10⁻⁶ J。设为事件会把每次溅水拆成大量短段，得不偿失。液体只能是矩形（圆形液体在解析时报错）。读数“物体中心处液体的压强（表压 ρgh）”代替“液体中某点的压强”。
- **R5（公式，组 E）。** 情形 `rail`、`float`、`zone-b`、`zone-e` 只由 Rust 识别（`formula/situations2655.rs`）；场区、液体与导轨作用的物体不再给出只考虑机械力的其他公式（`filter_regions`，含液体场景中的全部运动物体），“动量守恒”在这些场景中不成立。漂浮的平衡公式（`fl.eq`、`fl.ratio`、`fl.h`）是近似公式，以“物体已静止”为条件分级（仍在振动时显示“近似”）。收尾速度 `rail.vT` 以 e^(−t/τ) 分级；`rail.v` 是精确的指数解。推导中液体与物体的密度用 ρ_f、ρ_b，浮力 F_b（公式与读数的符号不含汉字）。
- **R6（识别修正）。** “抛体运动”与“单摆”情形在物体发生碰撞时分段（每次弹起是新的抛体段，单摆碰撞后是新的摆动段）。此前一次运行的多次弹跳合成一个抛体情形，公式在第一次弹起后全部偏离（新模板“弹跳的小球”暴露了这个 26.48 起就有的问题）。TypeScript 参照同步修改；现有模板中没有受影响的场景，两类对照仍为 0 处不一致。
- **R7（模板）。** 场区、液体与导轨模板是 Rust 专有场景（`usesFields` 扩展到场区与导轨回路，D77），共 23 个专有模板；其余新模板参照与 Rust 逐位相同。“弹跳的小球”给小球一个很小的水平速度：静止下落时每段抛体的中点恰是最高点（速度为零），v = √(v₀² + 2g(y₀ − y)) 在那里对高度误差极敏感，测试中曾判为偏差。
- **R8（视图）。** 无限时长的场景在算到原先的“有限时长”时再适合一次视图（此前只按第一块记录适合视图，物体运动较远的模板看不全）；手动平移或缩放后不再自动适合。场区与液体计入适合视图的范围。
- **R9（实验室细节）。** 量子：单位 ħ = mₑ = 1 nm（E₀ ≈ 0.0761996 eV，T₀ ≈ 8.638 fs），势能取格点单元平均（方势垒边界不落在格点上时也收敛）；波动光学：白光按 CIE 配色函数求和后按 D65 白点缩放，负的色通道截断为 0；结合能：AME2020 质量过剩表；磁场：磁感线是磁矢势 A_z 的等值线（精确），条形磁铁用等效面电流。
- **R10（界面文字）。** 新增界面文字 821 条，全部有英文与德文；`v2654.ts` 中 26.54 的“计划”实验说明（14 条）不再使用，已删除。快捷键表更新为 Alt+1 工作台、Alt+2 实验室、Alt+3 渲染与监视、Alt+4 设置，并加入 Ctrl+K 与触屏手势。
- **R11（文件版本）。** 发布前检查兼容性时发现：26.54 读格式 6 的场景不提示，却不认识场区、液体与导轨回路，会静默丢掉它们。因此用到这些功能的场景写为**格式 7**（`sceneVersionOf`；Rust `SCENE_VERSION` = 7，6 → 7 无需迁移），26.54 打开时提示“来自更新的版本”；其余场景仍为 5 / 6，文件与指纹不变。实验室文件同理：含 26.55 新元件的电路写为版本 2（26.54 的电路编辑器遇到未知元件会出错，版本 2 让它在导入时就给出“版本较新”的提示），其余实验仍为版本 1（`labVersionOf`，测试 `tests/formats2655.test.ts`）。
- **R12（半圆公式的条件）。** 制作宣传片时发现“回旋加速器”模板在 13 s 之后有两张偏差卡片（`zb.t` 区内时间、`zb.d` 弦长）：半径随加速增大，粒子从 D 形盒的另一侧提前射出，而条件 `semi` 只检查了“垂直于直边界射入”。条件改为同时要求半个圆周在区域内（半圆外接矩形的角点都在矩形区域内），不满足时这两条公式“不适用”并说明原因；质谱仪等模板不受影响。只改 Rust 的情形识别（这些情形本来就只在 Rust 中），测试 `tests/zoneSemicircle.test.ts`。
- **R13（模板“斜面上的连接体”）。** 同一次检查中发现：物块 m₁ 到达斜面顶端后被顶角抛起、越过滑轮落到另一侧，与 m₂ 在滑轮下纠缠，引起事件过密并改用 Moreau–Jean。模板改为 m₁ 撞到斜面顶端时停止（`stopAt: impact`，与“物块到达滑轮时停止”的阿特伍德机一致）。31 个新模板都在 max(3 × 原有限时长, 12 s) 内复查：没有警告、没有精度降级。
- **R14（电路实验的画面与示例）。** Windows 实机检查（构建 2）发现变压器的名称与匝数叠在一起；随后把 24 个示例逐个截图检查：竖直元件的名称与数值改为两行（宽度减半）；匝数写在两个线圈之间（n₁ 偏上、n₂ 偏下）；电表与探头的读数放在空间更大的一侧（与相邻竖直元件的间距，扣除朝向本元件的标签），在标签一侧时写在标签下方；漏电保护器的名称与额定值写在本体旁；适合视图左右各留 4.5 格给标签，格子最小 16 px。示例修正：“远距离输电”中小灯泡与降压变压器的副线圈画在同一条线段上（改为分开并加宽间距）；“家庭电路与漏电保护”中零线从第一盏灯的接线端旁穿过而没有连接，这盏灯从不发光（导线只在两端连接）；“测电源电动势和内阻”的电压表外移。`tests/circuitPresets.test.ts` 检查每个元件独占自己的线段、没有接线端落在导线中间。
- **R15（D92b 的实现范围）。** 机械效率实现为每个物体的两项读数：有用功 = 克服重力提升该物体的功（自运行开始），η = 有用功 / 外力、电机与传送带自开始做的功（取自能量账本，分支场景扣除 `startLedger` 中的初值）；只在有外力（含表达式力）或电机且有重力的场景中列出。手册原写的“沿任意方向的有用功”和“从选定时刻算起”没有做，可用自定义量表示，顺延到 26.56。
