# VeloPhi 26.54 开发手册

26.54 与 26.55 是一组：两版共同完成维护者的两项目标——**（一）重新梳理物理框架**：对照“初中 → 高中 → 大学”的物理路线图，列出 VeloPhi 已有与待扩展的全部内容，按难度分组，并在一个引擎里逐步覆盖从初中到大学的知识与模拟渲染；**（二）界面重新规划**：左侧工具、右侧公式都太密，加入折叠、分层与分类，主次分明。本手册包含两版共用的路线图总表、分组与版本分配（第 2–4 节），以及 26.54 的决策、工作分解与验收；26.55 的手册见 `docs/DEV_MANUAL_26_55.md`。原则、阈值与决策 D1–D74 继续有效。

**范围（2026-10-27，维护者提出）：** “1. 重新梳理物理学框架……请你查看哪些是已经有了的，哪些是还要扩展的，并列出一个完整表。然后，再把这些所有功能分组，从简单（只需要小改 UI + 一点点运算）到较困难（需要改 UI + 计算 + 运行时）。我的期望是能在这一个引擎里学完从初中到大学的所有知识，并完成全部的模拟渲染。例如电（导线，电阻，电容，传感器，电机，灯泡，串联，并联，电场，磁场……）核物理 / 量子物理……2. UI 重新规划。现在的 UI，左半部分全是密密麻麻的图案，右边全是密密麻麻的公式。请加入折叠 / 分层 / 分类，让内容主次分明，方便用户操作。3. 其他细节和修改，仍按照你的思路和现有手册进行开发。把以上目标平均分摊到两个版本，也就是 26.54 和 26.55……如果不太可能在两个版本内完成，则标注并顺延到后面的版本。”路线图原文：`E:\VeloPhi\roadmap.txt`（维护者整理，四个阶段：概念启蒙 → 数学强化 → 理论体系构建 → 高级分支）。

## 5. 界面问题与重新规划（26.54 部分）

现状（26.53，1389 × 868 的窗口）：左侧 27 个工具按 5 组全部展开，一屏只能看到 4 组，“对象”列表被挤到最下面；右侧 5 个页签，公式页一开头就是搜索框、密度切换、4 个下拉框、图例与说明，再往下才是公式，每个情形的全部公式同时展开；顶栏在宽窗口里并排 7 个显示开关。问题不在功能，而在**主次**：常用的东西没有比不常用的更显眼。

规划（D86）：

- **工具面板**：顶部是“常用”（固定 8 个）；下面是**分类页签**（物体 / 连接 / 力与场 / 编辑 / 标注），一次只显示一类；面板头部有搜索（按名称与快捷键找工具）与吸附开关（图标）；“对象”列表默认折叠，显示数量。工具多了（电荷、电场、磁场）也不会再变长。
- **右侧面板**：页签由 5 个减为 3 个——**分析**（公式 / 监视 / 预测，二级切换）、**属性**、**场景**；题目模式另加“题目”。
- **公式三层**：第一层是“情形概览”——每个情形一行：名称、时间段、公式数、判定小圆点、一条关键公式；当前时刻所在的情形自动展开，其余折叠。第二层是展开后的紧凑公式行；第三层是点开一行后的完整卡片。搜索框常驻；其余筛选、分组、显示不适用 / 超出水平的公式收进“筛选”抽屉，按钮上显示生效的条件数；图例收进“?”。
- **顶栏**：显示开关一律收进“显示”菜单，菜单顶部是四个预设（运动、受力、能量、简洁）；新增“实验室”页。
- **实验室页面**：左侧是按领域分组、可折叠的实验列表（电学、光学、原子与原子核、热学、相对论），每项标注学段（初中 / 高中 / 大学）；中间是实验画布；右侧是读数与公式（同样分层：结论在上，推导折叠）。

## 6. 本版决策

**D75 路线图与分组。** 第 2–4 节为 26.54 与 26.55 的共同范围；每完成一项，在总表“版本”列改为“已有（26.5x）”。新增内容一律按“现状 → 扩展 → 组 → 版本”登记，未登记的不做。

**D76 实验室框架。** 不适合放进二维刚体运行时的内容（电路、光路、原子、衰变、相对论、热学，以及 26.55 的波、量子、气体）做成**实验室**：

- 页面：顶栏新增“实验室”页（工作台、实验室、渲染与监视、设置；快捷键 Alt+1 … Alt+4）。左侧实验目录（领域分组、学段标签、可折叠），中间画布，右侧读数与公式。
- 计算：每个实验的物理计算是 Rust 核心中的无状态计算操作（`calc_call`，写入 `engine/CALC.md`，D67），界面只做编辑、绘制与显示（D65）。时间推进的实验（衰变；26.55 的暂态、波、量子）由 Rust 一次算出要显示的序列。
- 状态：每个实验的器材与参数保存在设置中（下次打开恢复）；“导出”给出 JSON（`velophi-lab`，版本 1），“导入”可恢复。
- 公式：实验右侧给出该实验的公式（代入当前数值，结果与 Rust 计算值并列），沿用公式面板的分层与样式。

**D77 新物理只在 Rust 中实现。** TypeScript 参照（D69）冻结在 26.53 的范围：它不认识电荷、电场、磁场，也没有实验室。验证方式改为解析解与守恒量（例如：匀强磁场中的圆周半径与周期、匀强电场中的偏转、库仑散射的偏转角与能量守恒、电路的基尔霍夫定律、衰变的期望值）。对照脚本与对照测试跳过使用了新功能的场景（`usesRustOnlyPhysics(scene)`），并检查这样的场景确实被跳过而不是被错误比较。

**D78 电荷与匀强电场、磁场（力学运行时，C 组）。**

- 物体增加电荷量 q（C，默认 0，只作用于动体的质心）。场景设置增加：匀强电场 **E**（V/m，向量）、匀强磁场 **B**（T，垂直纸面，正值指向纸外）、库仑相互作用（开关与 k，默认 8.99×10⁹ N·m²/C²）。
- 力：电场力 qE；洛伦兹力 q v × B（Fx = q·vy·B，Fy = −q·vx·B）；库仑力 k q₁q₂/r²（与万有引力相同的软化：两物体包围圆相交时线性减小）。静止物体的电荷也产生库仑力（固定点电荷）。
- 能量：匀强电场的电势能 −q E·r（零点为坐标原点）与库仑势能 k q₁q₂/r（软化区内用与力一致的势）计入机械能；洛伦兹力不做功。能量账本、能量柱、“能量守恒”公式卡片随之更新。
- 读数：电荷量、电场力、洛伦兹力、电势能；受力显示与受力分析图中新增“电场力 F电”“洛伦兹力 F洛”。
- 画面：有电场时画匀强场的场线（虚线箭头），有磁场时画 ⊙ / ⊗ 点阵；有电荷时可显示电场线与等势线（D79）。
- 情形与公式：“带电粒子在匀强电场中”（a = qE/m，类平抛的位移与偏转角）、“带电粒子在匀强磁场中的圆周运动”（r = mv/(|q|B)，T = 2πm/(|q|B)）、“速度选择器”（v = E/B 时匀速直线）、“库仑相互作用”（F = kq₁q₂/r²，能量守恒）。
- 模板：带电粒子在电场中偏转、回旋运动、速度选择器、两个带电小球、α 粒子散射。
- 场景格式：字段可选；用到电荷或场的场景写为格式 6（26.53 打开时会提示“文件来自更新的版本”），其余仍为格式 5，指纹不变。

**D79 电场线与等势线（B 组）。** 场景中有电荷时，“显示”菜单提供“电场线”“等势线”：由 Rust 在当前帧计算（点电荷 + 匀强场的合场），电场线从正电荷出发、按电荷量分配条数，用自适应步长积分到负电荷、画面边界或长度上限；等势线用网格上的势值做行进方块（marching squares）。

**D80 直流电路实验室（B 组）。**

- 器材：电池（电动势、内阻）、导线、开关、定值电阻、小灯泡（额定电压与功率；电阻按额定值，亮度 ∝ 实际功率 / 额定功率）、滑动变阻器（总阻值、滑片位置）、电流表、电压表（理想或给定内阻）、电容器（稳态：开路，显示 Q = CU）、保险丝（26.55）。
- 编辑：元件放在网格的两个格点之间（拖出），端点相同的格点自动连通；可旋转、删除、修改参数；开关点一下切换。
- 求解：Rust 中的改进节点分析（MNA），未知量为节点电势和电压源（含电流表）电流；方程用现有的完全主元消元求解（秩检查）。理想电压源短路、电压源并联矛盾、悬空支路分别给出说明，不出现无穷大。
- 显示：每个元件的电压、电流、功率；导线上的电流动画（方向为正电荷移动方向，速度随电流）；小灯泡按亮度发光；电表读数显示在表盘上；节点电势可按颜色显示。
- 分析：选中两点给出等效电阻；串联 / 并联关系的判断与说明；公式（欧姆定律、闭合电路欧姆定律 I = E/(R + r)、串并联、P = UI = I²R）。

**D81 几何光学实验室（B 组）。** 光源（单束光线、平行光、点光源、物体箭头）、平面镜、球面镜（凹 / 凸）、薄透镜（凸 / 凹）、玻璃砖、三棱镜、半圆玻璃、屏。两种模式：**成像**（主光轴上的物与薄透镜 / 球面镜：三条特殊光线、像的位置、放大率、正倒与虚实，1/u + 1/v = 1/f）与**光线追迹**（任意摆放的元件：反射定律、折射定律、全反射、色散——棱镜对红绿蓝三色取不同折射率）。计算在 Rust 中：薄透镜按近轴折射规则，球面镜与玻璃按真实几何（因此可见球差）。

**D82 原子与光（B 组）。** 两个实验：**氢原子能级与光谱**（Eₙ = −13.6 eV/n²；选上下能级给出光子能量、频率、波长与谱线系：莱曼、巴耳末、帕邢；巴耳末线在可见光谱中的位置）；**光电效应**（选金属（逸出功表）、光的频率与强度、两极电压；给出光电子最大初动能 Ek = hν − W、遏止电压、饱和电流、I–U 曲线，截止频率以下没有电流）。

**D83 放射性衰变（C 组）。** N₀ 个原子核（点阵显示），给定半衰期；每一步每个核按 p = 1 − 2^(−Δt/T½) 随机衰变（Rust 中的确定性随机数，同一种子结果相同），给出 N(t) 曲线与理论 N₀·2^(−t/T½) 对照，以及“剩一半”的时刻统计。

**D84 狭义相对论（B 组）。** 参考系 S 与以速度 v 运动的 S′：γ、时间延缓（光钟）、长度收缩（尺）、洛伦兹变换（在闵可夫斯基图中点选事件，给出两个参考系中的坐标）、速度合成、相对论动量与能量（E² = (pc)² + (mc²)²）。

**D85 热学（B 组）。** **加热曲线**：恒定功率加热冰 → 水 → 水蒸气，给出温度—时间曲线与熔化、沸腾平台（Q = cmΔt、Q = mL），可换物质；**热平衡**：两种物质混合（质量、比热容、初温），按热交换速率给出两条温度曲线与平衡温度 t = (c₁m₁t₁ + c₂m₂t₂)/(c₁m₁ + c₂m₂)。

**D86 界面分层（见第 5 节）。** 实现约束：全部开关与折叠状态存入设置（下次打开恢复）；新布局在 1280 × 720 与投影模式下不出现横向滚动；所有新文字三语齐全。

**D87 力学的 A 组条目。** 模板：惯性演示、轮轴、电梯中的弹簧秤、三种宇宙速度、受迫振动与共振、α 粒子散射；观测量：每个力与每个物体的功率、机械效率（有用功 / 总功，需指定“有用”的物体与方向）、系统的 T、V、L、H、开普勒读数（周期、半长轴、偏心率、面积速度）；曲线面板增加“相图”方式（任意两个量的 y–x 图，默认 x–vₓ）。

### 10.2 决策修订与实现说明

- **R1（D77，跳过 Rust 专有场景）。** 判断函数实际名为 `usesFields(scene)`（任一物体带电，或设置了电场、磁场、库仑力；含分支场景）；`referenceTemplates()` 给出参照能运行的模板。对照脚本（`parity.mjs`、`calc-parity.mjs`、`bench.mjs`）与对照测试只用这些模板；`tests/rustOnly.test.ts` 检查：跳过的正是 5 个电磁模板，它们的 Rust 指纹确实与参照不同（因此比较会出错，而不只是多余），带电场景写为格式 6、其余仍为格式 5，电荷为 0 的场景与参照逐位相同。说明：平衡的速度选择器（v₀ = E/B，qE 与 qv₀B 逐位相等）与无场运动逐位相同，测试用 v₀ = 3 的变体。
- **R2（D78，情形与公式）。** 除手册列出的四类情形外，增加“在电场和磁场中运动”（`charge-eb`：速度选择器不平衡时，用动能定理 W = qE·Δy 与洛伦兹力功率为零），共 5 类情形、21 条公式（`ce.*`、`cb.*`、`sel.*`、`ceb.*`、`cl.*`），全部有三语推导（`src/formula/derivations/d-electric.ts`，组 D）、学习手册专题“电与磁”与例题（例题取自 Rust 核心的识别结果；`alpha-scattering` 的 b = 0、`velocity-selector` 的 v₀ = 3 两个变体）。公式量纲增加第四个基本量纲“电荷”（`Dim` 的第 4 个分量，可省略），新单位 C、V/m、T、V、A、Ω、F、N·m²/C²、C/kg。带电物体上不再给出只考虑机械力的公式（`filter_electric`）。
- **R3（D78，动量情形）。** 识别“动量守恒”时，匀强电场 / 磁场、固定电荷、有万有引力的静止物体、锚点不动的有心力、空气阻力、以及一端固定的焊接 / 滑轨 / 马达都算外力，系统不再被识别为动量守恒。这同时修正了 26.51 起已有的问题：“行星绕恒星运动”模板曾给出偏差很大的“动量守恒”卡片。TypeScript 参照同步修改（不涉及电磁的部分），两类对照仍为 0 处不一致。
- **R4（D78，力与能量）。** 库仑力的软化与万有引力相同（两物体包围圆相交时线性减小，势能与力一致）；静止物体的电荷是固定点电荷。受力分析图的力类别顺序：…… 电场力、洛伦兹力、库仑力、其他。电荷只在质心；有电场或带电物体时，“场景”页显示电场 / 磁场 / 库仑力设置，“属性”页显示电荷（否则折叠）。不用新功能的场景：Rust 指纹与 26.53 相同（`engine/velophi-core/tests/electric.rs` 与全部对照）。
- **R5（D79）。** 电场线与等势线由实验室的 `fieldMap` 操作计算（工作台与“电场线与等势线”实验共用 `labs/field.rs`），工作台在当前帧的电荷位置上缓存结果。匀强电场的场区充满整个空间；“带电粒子在电场中的偏转”模板画出极板与荧光屏（静止物体），有界场区在 26.55（D90）。
- **R6（D80–D85，实验室）。** 电路：改进节点分析中，导线、闭合开关与理想电流表用并查集合成超节点，电容器所在的孤立部分按电荷中性补方程，悬空部分取最小范数解并给出说明；等效电阻在去掉电源后计算（理想电源换成导线会把两端短接）；保险丝顺延 26.55。光学：成像（近轴，三条特殊光线）与光线追迹（真实几何：斯涅尔定律、全反射、菲涅耳部分反射、柯西色散）分为两个实验。原子：氢原子画到汉弗莱系，巴耳末系可见线 5 条（Hα–Hε）；光电流用量子效率 5 % 与收集效率的简化模型（实验说明中写明）。衰变：SplitMix64 与几何分布抽样，同一种子逐位可重复。相对论：γ − 1 用 β²/(s(1 + s))（s = √(1 − β²)）计算，低速时不丢精度。热学：加热曲线与热平衡为闭式解（牛顿冷却定律）。
- **R7（D87，惯性模板）。** 用“抽纸条”代替“小车突然停止时车上的木块”：现有的摩擦模型就能清楚地显示惯性（快速抽出时物块几乎不动，减小拉力后随纸条移动），不需要突然停止的冲击。
- **R8（D87，机械效率）。** 26.54 用自定义量给出：“斜面的机械效率”模板中 η = ep(物块)/(ep(物块) + heat(物块, 斜面))，与 sinθ/(sinθ + μcosθ) 对照；通用的“有用功”指定（选物体与方向）顺延 26.55（已写入 26.55 手册）。
- **R9（D87，开普勒读数）。** 周期、半长轴、偏心率、掠面速度由 26.51 的“轨道”情形公式卡片给出（`or.T`、`or.A`、`or.ecc` 等，含仿真测量值）；新增的系统读数“对原点的角动量 L”给出 L = 2m·dA/dt。
- **R10（D87，轮轴与相图）。** 轮轴模板：轮与轴是焊接在一起的两个同心圆盘，绕中心铰接；轴上挂重物、轮缘用绳竖直拉住，读数“省力倍数 G/F”等于 R/r（绳系在边缘的点上而不是缠绕，模板处于平衡，因此与缠绕等价）。相图：曲线面板的“相图”按钮切换为任意两个量的 y–x 曲线（预设 x–vₓ、θ–ω），当前状态用圆点标出，点击曲线跳到该时刻（`PhasePlot.vue`）。
- **R11（D87，参照）。** 新读数 P、L、拉格朗日量、哈密顿量同步加入 TypeScript 参照（运算顺序相同），计算对照覆盖它们。
- **R12（无头浏览器检查后的修正）。** 用 Windows 构建的 WebAssembly 在无头 Chromium 中走查工作台与 10 个实验（1389 × 868 与 1280 × 720 均无横向滚动、无脚本错误）后修正：理论值恰为 0 的公式（如洛伦兹力的功率）不再显示“相对误差 100 %”，改显示绝对误差，相对误差 ≥ 100 % 时也不再写成 `1.0e+2%`（26.53 已有的显示问题）；实验公式卡片的左边用 KaTeX 显示（此前显示为去掉反斜杠的 LaTeX 源码），过长的公式可横向滚动；电路中竖直元件的名称与读数放在元件旁边而不是压在符号上；“带电粒子在电场中的偏转”在小球撞到极板或荧光屏 0.3 s 后停止（场充满整个空间，否则小球沿荧光屏一直加速下落）；氢原子实验中光子能量与能级差之差 ≤ 0.005 eV 即可被吸收（教材的 12.09 eV、12.75 eV、13.06 eV 都能使基态原子跃迁，此前的 0.001 eV 把 12.09 eV 判为不能吸收）；热平衡的曲线加高；相图的纵轴标题去掉物体名。
